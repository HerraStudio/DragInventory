# 工厂战术地图

重做工厂战术地图界面，视觉参考三角洲行动的深色俯视地图：全屏底图、半透明侧栏、绿色位置指示、低对比度网格与底部操作提示。

## 操作

- `M` 打开或关闭，`Esc` 关闭；不暂停游戏。
- 左键拖动，滚轮以鼠标位置为中心缩放，空格或「定位」回到玩家。
- 右键或中键在已加载的地形上添加地点标记。与世界 HUD 共用 5 个标记名额、60 秒生命周期。
- 左侧列出真实地点、敌情、物资标记及距离、剩余秒数。点击条目将地图移到标记位置。「清除标点」只清除地点标记。
- 右侧点击图例行可隐藏/显示该类标记，不会删除标记；Shift 隐藏/显示整个右侧图例。
- 地图固定使用工厂范围 `X=-48..352, Z=-176..64`，不会因为玩家移动扩张或重新定位到整个 Minecraft 世界。打开地图后在这个固定范围内扫描已加载区块，按可行走平面识别主要楼层、地下层、平台和特殊高度区域，并为每层建立独立的预渲染地图。地图只显示玩家所在区域与高度对应的一层；玩家走上楼梯、进入地下层或跨入另一个区域时自动切换，不再提供手动楼层按钮。

## 显示与边界

底图来自客户端已加载区块，不包含虚构撤离点、任务或资源点。未加载区域保留深色且不能添加地图标记。建筑/地形的外观由当前世界决定；截图里的工厂是隔离测试场景，未随模组添加到玩家世界。

玩家朝向使用上北下南、左西右东的固定坐标。标记只显示在当前楼层附近，避免其他楼层内容叠加。窗口变小或 GUI 比例提高时，界面与输入坐标一起缩放，保证侧栏不重叠。

底图使用每楼层独立的 1024×1024 预渲染纹理，纹理过滤开启并使用邻域平滑采样；当前楼层优先、其他楼层后台生成。地图只使用冷色地面、亮色边界、深色墙体、金色楼梯和蓝色水体等战术语义色，降低原版方块颜色造成的杂讯，并叠加楼梯/电梯连接点。关闭界面释放全部楼层纹理。地图边界固定，区域外保持深色空白；拖动与缩放会被限制在固定工厂范围内。

工厂存档位置：`D:\MineCraft\.minecraft\versions\1.21.1-NeoForge_21.1.251\saves\工厂`。地图运行时读取当前客户端世界中的区块数据，存档本身不被修改；进入该存档并保持工厂周边区块加载后打开地图即可建立楼层缓存。

## 开发验证

```powershell
.\gradlew.bat test build
.\gradlew.bat runClient -PmapSmoke -PweaponGameDir=run-map-redesign
.\gradlew.bat clean test build
```

`mapSmoke` 仅用于隔离验证，自动创建测试世界并生成工厂建筑，检查自动楼层发现、独立预渲染、拖动与缩放、地图标点、侧栏输入隔离、GUI 缩放、图例隐藏、关闭重开和纹理释放。正式构建不要传入此参数。

源码：`src/main/java/dev/draginventory/client/map/`。中文与英文文字位于各语言 JSON，颜色和图标集中在 `FactoryMapUI`，采样和分帧纹理分别在 `FactoryMapSampler`、`FactoryMapTexture`。
