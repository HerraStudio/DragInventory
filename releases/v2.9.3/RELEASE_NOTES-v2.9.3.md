# Drag Inventory v2.9.3 — 声纹竖条高度硬顶棚 + 出厂预设精确固化

本版针对实测反馈两项：**恢复默认后位置预设与垂直微调Y等值与用户预设不符**、**声纹竖条整体失控（每条都非常长、看不出律动、挡屏幕）**。核心修复是把竖条渲染高度加**数学硬顶棚**（任何加成叠加后单侧不超 `max_height × 类型加成`），并把用户实测调优的七值**原样固化为出厂预设**。

## 一、竖条高度硬顶棚（根治"每条都非常长、挡屏幕、看不出律动"）

### 根因（v2.9.0~v2.9.2 为什么竖条会超长）
- 单条竖条的渲染高度此前**叠加全部乘子**：`max_height × 枪声加成 1.35 × 垂直不对称（最高 1.75）× 抖动（最高 1.26）`；
- `max_height=24` 实际能画到约 **71px——配置值的约 3 倍**；GWO 垂直交战（楼上楼下）时垂直不对称直接拉满 1.75，加上 GWO 自定义声音音量普遍 ≥ 基准响度（能量钉满 1.0），整簇竖条以越顶高度钉满屏幕；
- 与配置语义直接冲突：toml 注释明言 `max_height` 决定声纹几何"最大高度"，实际渲染却最高 3 倍越顶——名不副实。

### v2.9.3 顶棚数学（SoundPrintEnvelope.cappedBarHeight）
- **抖动前基底先钳到 `cap/(1+抖动幅度)`，再乘抖动系数**——最终单侧高度**数学上永不超** `cap = max_height × 类型加成 × 错位缩放`（枪声 1.35 倍保留，错位模式 0.82 等比保留）；
- **满能量中心条在顶棚内持续舞动**（`(1-amp)/(1+amp)×cap` 与 `cap` 之间摆动，约 ±10%~±13% 摆幅）而非钉死在硬钳位上——v2.9.2 的"常驻随机振动"节律完整保留；
- 顶棚以下的小条**原样通过**（抖动乘子照常），钟形包络、上下不对称（只重分配上下占比、不再放大越顶）、渐变/柔光/圆角、方向箭头全部不受影响；
- 布局预留带（`Hud` 控件高度公式 `2×(max_height×1.35×1.8+ampMax+3)`）与基线位置**零改动**——v2.9.1/v2.9.2 调好的位置微调值落点不变。

### 效果对照
| 场景 | v2.9.2（越顶） | v2.9.3（顶棚） |
|---|---|---|
| 脚步簇满能量（max_height=24，水平声源） | 中心条 ~24px | 中心条 ~24px（不变） |
| 脚步簇满能量 + 声源在楼上/楼下 | 中心条最高 **~53px（2.2 倍越顶）** | 最高 24px |
| 枪声簇满能量 + 垂直偏移 + 抖动拉满 | 中心条最高 **~71px（3 倍越顶）** | 最高 32px（= 24×1.35 枪声加成保留） |
| 满能量观感 | 部分条钉死在越顶高度，"看不出律动" | 每条在顶棚内独立舞动，节律可见 |

## 二、出厂预设精确固化（根治"恢复默认后与预设值不符"）

### 根因
- v2.9.1 做位置出厂预设固化时，**用户原报的具体数值已随上下文丢失**，当时按上轮反馈方向**猜测性定档**（below_compass + spacing 4 + width 260 + offset 0/0 + opacity 0.9）并在 RELEASE_NOTES 明示可回传 `/soundprint status` 精确重固化；
- 用户实测点"恢复默认"后看到的正是这组猜测值——与真实预设不符。

### v2.9.3 出厂预设（用户实测反馈七值**原样固化**）
| 常规页设置 | v2.9.2 默认 | **v2.9.3 默认** |
|---|---|---|
| 不透明度 | 0.90 | **1.00** |
| 与方位条间距 | 4 px | **0 px** |
| 整体缩放 | 1.00 | 1.00（不变） |
| 位置预设 | below_compass | **bottom_center** |
| 水平微调 X | +0 px | +0 px（不变） |
| 垂直微调 Y | 0 px | **-174 px** |
| 条带宽度 | 260 px | **380 px** |

- 设置页脚**"恢复默认"**按钮或 `/soundprint reset` 一键回到上表七值（全部 45 项配置同步回出厂值）；
- **老配置兼容**：已有配置文件的值**不改动不覆盖**（升级只换默认值定义，不动用户自定义）；想吃到新预设就点一次"恢复默认"；
- 其余 38 项配置默认值全部不变（检测/形态/动画/多声源各组维持 v2.9.2 状态）。

### 附带修复：构建缓存陷阱（发布基础设施）
- `processResources` 的 `filesMatching{ expand }` 注入值不参与构建缓存键——温缓存下版本号 bump 不失效该任务，jar 内置 `neoforge.mods.toml` 会残留**上一版版本号**（本次 v2.9.2→2.9.3 实测命中，v2.9.2 冷构建未暴露）；
- 修复：`inputs.property('modVersion', project.version)` 显式声明任务输入，缓存键随版本变更——本版 jar 已验证内置 `version="2.9.3"`。

## 复测清单

1. 装入 v2.9.3（配置兼容，无需删旧配置）；
2. **恢复默认核对**：设置 → 声纹 → 常规页点页脚"恢复默认"——七项应精确显示：不透明度 1.00 / 间距 0 px / 缩放 1.00 / 位置预设 Bottom center / X +0 px / Y -174 px / 宽度 380 px（`/soundprint status` 的 position 段同值核对）；
3. **高度顶棚**：进入 GWO 垂直交战（楼上楼下枪声）——竖条单侧最高不超过 形态页"最大高度"×1.35（枪声），不再有超长条挡屏幕；
4. **节律**：满能量时竖条仍每条独立舞动（顶棚内收缩拉长），声音停止按收尾衰减收拢归零；
5. **位置落点**：恢复默认后条带应悬在快捷栏上方（bottom_center 基础位上移 174px），如需微调 X/Y 实时生效；
6. **错位模式**：多声源并排错位（mode=stagger）时簇尺寸等比缩小，顶棚同步等比；
7. mod 列表 / 崩溃报告（如有）显示 draginventory@2.9.3。
