# Drag Inventory 2.5.1 —— 错误修正

本版修复 2.5.0 升级玩家遇到的"所有 UI 不显示"问题，共四处修正，无新增玩法内容。

修正一（最重要）——升级后 M 键失灵、小地图消失：旧版本配置文件里残留的"总开关 = 关闭"状态在 2.5.0 接线生效后会静默禁用 M 键与常驻小地图，且此前的自动迁移在玩家运行过任一版 2.5.0 后即告失效。本版改用一次性迁移标记：首次加载时无论配置文件处于什么结构，一律把残留的关闭状态复位为开启；此后你主动执行的 /map off 会被正常尊重。装上本版后 M 键与小地图立即恢复。

修正二——打开地图"什么 UI 都没有"：2.5.0 的"打开即清屏"默认已取消，现在打开大地图默认显示完整界面（顶栏、工具栏、缩放按钮等一应俱全）；如果你想要"开图只看地图、背景和玩家位置"的清屏效果，在设置界面视觉页打开"打开时进入清屏模式"开关即可，地图内 H 键也随时可以来回切换。标点显隐始终由标点管理菜单决定，不受清屏影响。

修正三——地图内按数字键 1/2/3 "没反应"：切换标点类型（地点/敌情/物资）与 C 键清除标点现在会在地图底部弹出短暂提示（例如"已选择标点类型：敌情标记"），操作即刻可见。

修正四——地图持续闪烁：楼层目录定期重建时的集合抖动会让活动楼层被误判切换，在 2.5.0 的渐进烘焙下表现为地图（尤其玩家所在区域）反复重烤闪烁。本版将楼层身份改为楼层 Y 值（重建不再误判）、自动换层增加迟滞（候选层不比当前层更近就不切换）、静止时楼层重扫描从 2 秒降频到 10 秒（消除周期性卡帧）、小地图楼层跟随加 ±2 格死区防抖。

适用：Minecraft Java 1.21.1 + NeoForge 21.1.251 + LDLib2 2.2.40（或 2.2.41），Java 21。直接替换 mods 内旧版 JAR 即可，配置无需手动改动。
