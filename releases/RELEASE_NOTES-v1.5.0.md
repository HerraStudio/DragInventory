# Drag Inventory v1.5.0 — 五套游戏风格方位条 + 全新设置界面

> Minecraft 1.21.1 · NeoForge 21.1.251 · 依赖 LDLib2 2.2.40+
> 安装：将 `drag-inventory-1.21.1-neoforge-1.5.0.jar` 放入 `mods/` 目录。
> 从 1.4.x 升级：直接替换 jar 即可，旧皮肤配置自动回退到 `delta`（三角洲行动）。

## 本版本亮点

### 皮肤体系重做 — 五套游戏还原（实机截图比对 + 视觉模型逐项校对）

- **delta 三角洲行动**（默认）：高不透明深色条带、上缘受光高光 + 下缘深影、条带内两端渐隐、中心大号度数胶囊 + 下指小三角。
- **pubg 绝地求生**：近无底透明条带、**顶部大号当前度数（无底衬）+ 白色下指三角**、大号方位字、15° 等宽数字位于刻度正下方、两端硬截止（原作同款）。
- **apex Apex 英雄**：磨砂深色条带 45° 斜切端 + 细亮描边、条带下方**大号度数切角底衬框**（细亮描边）+ caret 指示。
- **battlefield 战地**：无底色丝带——刻度基准线 + 两端 L 形包角 + 顶部小三角，条带下方大号度数读数。
- **warzone 使命召唤**：圆角半透明条带 + 顶部白色下指三角 + **条带下方单行"方位名 + 度数"读数**（如“北 353”，COD 同款格式）。
- 六组配色（极光/霜白/琥珀/绯红/紫罗兰/石板）与任一皮肤自由组合，颜色逐项可覆盖。

### 设置界面彻底重做（像素游戏风）

- 原版 Screen 自绘：像素切角面板、深色双层描边、贴合 Minecraft 画风。
- **六页签单屏容纳全部选项**（外观/布局/显示/标点/动效/颜色）——彻底告别旧版"滚很久才看到选项"的长列表。
- 顶部实时预览与 HUD 同一渲染路径：拖拽转向、模拟朝向滑杆、自动摆动。
- 动效全套：开场缩放淡入、页签切换上滑、开关滑块动画、滑杆悬停高亮、按钮按压反馈。
- 颜色页内置 HSL 取色器（色相彩虹条 + 饱和/明度微调），一键"跟随配色"还原。

### 修复与改进

- **移除"黑色哑铃"**：旧版全高边缘遮罩在条带两侧形成哑铃状黑色块体并遮挡下方内容，已彻底删除。
- **实拍参考视觉校对**：基于网络实机截图裁剪 + 视觉模型逐项提取设计基因，五套皮肤逐项修正还原度（PUBG 重做、Apex 补招牌切角底衬框、三角洲底边深影、战区 COD 化、战地读数放大）。
- `/com` 快捷指令：打出前三个字母回车即唤出设置界面。
- 文字排版全面修正：标签列/控件列/数值列三列对齐；面板高度按 9 行预留，全部页签零滚动。
- 预览渲染脱离 LDLib UI 树（`renderStandalone`），设置界面与 HUD 共用同一绘制路径。

## 指令速查

```
/com                      # 快捷打开设置界面（也可 /compass）
/compass style delta|pubg|apex|battlefield|warzone
/compass palette aurora|frost|amber|crimson|violet|slate
/compass toggle|on|off    # 开关
/compass test enemy|location|item|clear   # 测试标点
/compass copy             # 朝向+方位名进剪贴板
/compass reset            # 恢复默认
```
