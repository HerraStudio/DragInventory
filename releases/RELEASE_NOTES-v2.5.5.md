# Drag Inventory 2.5.5 —— 对局计时实装与缩放范围调整

本版应实测反馈做出两项改进：小地图下方的"对局还有 X 结束"从静态占位升级为真实倒计时（含一整套醒目化与流动动效），大地图缩放范围调整为 108%~600%。地图功能的基础开发至此完毕。

改进一——对局计时实装（小地图计时行）：

- 真实倒计时：此前该行永远是 10:00 静态占位；现在每次进入世界按默认时长（10 分钟）自动开始倒计时，进对局时用 `/map timer 25:00`（或 `30m`）对一次表即可，`/map timer default 30m` 可把默认时长存下来（以后每次进世界自动按此时长开始）。
- 时长写法自由：冒号式 `25:00` / `1:30:00`、后缀式 `30m` / `90s` / `1h30m`、纯数字按分钟计（`25` = 25 分钟）；`/map timer` 查状态、`/map timer reset` 重置、`/map timer off` 关闭（下次进世界自动恢复）。
- 整行加粗：计时行文字全部加粗，小字号下也更易读。
- 时间值醒目变色：倒计时数字用醒目金色，与前后文字明显分层；最后 60 秒转为红色并加速闪烁，结束前一眼可辨。
- 时间流动动效：每秒秒位跳变的瞬间时间整体轻微脉冲放大再落回，冒号以 1Hz 呼吸明暗——数字"活"了起来；归零后整行显示红色"对局已结束"。
- 计时基于真实时间戳：暂停菜单、掉帧都不影响走表；换维度视为新对局自动重置。
- 联动预留：模组读不到服务器内部的对局剩余时间（服务器不下发该数据），故采用手动对表方案；将来对局系统实装后注册预留接口即自动接管真实值，渲染层零改动。

改进二——大地图缩放范围 108%~600%：

- 最小缩放从 17%（0.25）上调到 108%，最大缩放从 533%（8.0）上调到 600%——满足"默认打开就够近、上限拉得更远"的使用习惯。
- 旧版本升级用户无需手动改配置：首次加载时仍为旧默认值（0.25 / 8.0）的会自动收敛到新默认（1.62 / 9.0）并保存；此前自己调过其他值的玩家不受影响。
- `/map zoom min <1.08..2.0>` / `/map zoom max <2.0..16.0>` / `/map zoom reset` 与设置 GUI 行为页滑条同步更新；右下角缩放百分比读数口径不变。

其他：`/map info` 汇总从九项增至十项（新增对局计时）；新增 `MapMatchTimerTest` 单元测试（时长解析三种写法、倒计时数学、Provider 优先级与关停语义共 11 组断言；全套 153 用例 0 失败 0 错误）；wiki 新增《战术地图》完整使用手册。

适配说明：旧配置无需手动改动（zoom_min/zoom_max 旧默认值自动收敛，一次性标记 behavior.zoom_retuned）。适用：Minecraft Java 1.21.1 + NeoForge 21.1.251 + LDLib2 2.2.40（或 2.2.41），Java 21。直接替换 mods 内旧版 JAR 即可。
