# Drag Inventory 2.6.0 —— 玩家图标大小可调 + 倒计时只留数字

本版两项交付，均来自用户实机反馈：①玩家位置图标大小可以自定义了；②对局结束倒计时只保留数字本体。玩家图标的纹理管线（v2.5.9 刚修复的显示链路）零改动——大小调整只在绘制缩放层叠加倍率，不存在"改大小改出不显示"的风险。

功能一——玩家位置图标大小可调：

- **入口**：设置界面（`/map gui`）标点页新增"玩家图标大小"滑条，或指令 `/map player_size <0.4~1.0>`（反馈按百分比显示，如 `80%`）。
- **范围**：1.0 = 默认尺寸（**上限**，形状高 ≈12.5px，即 v2.5.7 以来的视觉大小），最小 0.4（≈5px，小地图上仍清晰可辨）；默认 100%，升级无感。
- **作用域**：小地图、大地图、设置页预览三处视图与尾迹残影全部等比缩放；设置页预览实时所见即所得（调的就是实际渲染路径）；`/map reset` / "恢复默认"一键回 100%。
- **实现安全性**：只把 `FactoryMapUI.player()` 的 pose 缩放乘上配置倍率（`markers.player_marker_size`，0.4~1.0），纹理加载与绘制（SimpleTexture + `.mcmeta` 线性过滤 + `GuiGraphics.blit`）一字未动——不重蹈 v2.5.8 图标不显示的覆辙。

功能二——对局结束倒计时只留数字：

- 小地图下方居中仅显示 **m:ss 加粗数字本体**，不再携带"对局还有……结束"前后缀文案（中英文均生效）。
- **颜色不变**：常态醒目金、最后 60 秒转红。
- **动效全保留**：每秒秒位跳变时数字轻微脉冲放大、常态冒号 1Hz 呼吸明暗、紧急段 2Hz 加速闪烁、归零显示红色"对局已结束"。
- 位置不变（小地图下方居中）；超长倒计时 × 最小尺寸小地图的极端场景仍有 0.8 缩排兜底。

其它：

- 新增配置 `markers.player_marker_size`（默认 1.0，热重载即改即生效）与语言键双语（`player_size` 滑条标签 / `cmd.player_size` 指令反馈）；清理死键 `match_timer`（前后缀拆分逻辑已随功能二移除）。
- 全套 **180 用例 0 失败 0 错误**。
- 实机复测要点：标点页滑条拖动时预览箭头实时缩放且最小档清晰可辨；调小后小地图/大地图箭头与尾迹等比缩小、边缘依旧平滑；倒计时行只有数字且居中，末 60 秒红闪与秒位脉冲正常；`/map player_size 0.4`~`1.0` 反馈百分比正确，越界报错。

适配说明：纯客户端变更；新增一个可选配置键（默认值与现状一致，不迁移）。适用：Minecraft Java 1.21.1 + NeoForge 21.1.251 + LDLib2 2.2.40（或 2.2.41），Java 21。直接替换 mods 内旧版 JAR 即可。
