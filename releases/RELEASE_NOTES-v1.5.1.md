# v1.5.1 — 用户参考图逐像素还原

**本版核心**：用户提供的 imgur 参考图（Apex / PUBG 罗盘条 + Mythic 客户端风格菜单）到手后，三套皮肤**按参考图逐项重写**，设置界面按参考图实测色 Mythic 化，并修复一个影响深远的坐标空间 bug。

## 三套皮肤重做（对照参考图逐像素还原）

### 三角洲行动（默认皮肤）
- 顶部一条贯穿全宽的**细基线**，所有刻度从基线**向下垂挂**（15° 位 2px 粗 10px 高，5° 位 1px 细 6px 高）
- 文字在刻度下方：八个方位点显示**方位词**（"北"为金色高亮），其余 15° 位显示**三位补零度数**（015 / 030 / 105…）
- 中心是嵌在条带里的当前朝向大读数 **[ 37 ]**：深色底衬 + 左右方括号 + 约 2 倍字号白色粗体 + 正下方一枚下指三角

### 绝地求生 PUBG
- 垂直层次按参考图重排：**顶部白色下指三角**（屏幕中心固定）→ 半透明圆角深色条带 → **刻度带在上** → **文字带在最底**
- 刻度分级：字母位（N/E/S/W/NE/SE…）**3px 粗刻度**、数字位 1px 细暗刻度；**N 的刻度与字母都是金色**（PUBG 招牌）
- 无当前度数大读数、无中心数值框（与参考图一致），两端硬截止

### Apex 英雄
- 参考图为**悬浮式**：无条带、无中心指示、无读数框（旧版全删）
- 八个方位点全部**大号字母**（约为数字 2.3 倍高），与数字共用底基线
- 角度数字小号，正上方一根**细刻度**（2px×10px）；字母位不画刻度（字母本身就是刻度）
- 两端 Alpha 渐隐，仅一层 0.13 极轻压暗保证亮天空下可读

## 重要修复

- **坐标空间 bug（P0）**：刻度/标签/标点原先使用裸常量 y 坐标，只在默认 offset_y≈6 时碰巧显示正确——**调大纵向偏移或打开设置界面预览时，刻度和标签会漂到条带上方几十像素处**。现已统一为相对坐标，任意偏移与预览均正确。
- **默认步长对齐参考图**：数字间隔 30°→**15°**、次级刻度 15°→**5°**。老配置保留你的自定义值；想获得参考图同款密度，在设置界面点一次"恢复默认"即可。

## 设置界面 Mythic 化（参考图实测色）

- 全套配色换为暖深灰 + 金：`#1E2326` 面板 / `#2B3236` 内衬 / `#4A555C` 描边 / `#D4A056` 金强调
- 标题栏：**金色竖线 + 主标题 + 副标题**（"按你的习惯调整 · 设置即时保存"）
- 页签：切角描边盒，选中态金框金字 + 底部金线
- **每行右侧新增 ↺ 按钮**：单项恢复该行默认值（悬停变金）
- 页脚：**返回**（左）/ 快捷键提示（中）/ 恢复默认 + 完成（右）
