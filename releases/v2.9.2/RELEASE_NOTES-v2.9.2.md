# Drag Inventory v2.9.2 — 声纹常驻随机振动 + 现代风格渲染

本版针对实测反馈两项：振动动画要**常驻**（有声源就永远在"活"，不定格）、渲染风格去像素化改现代。核心是把 v2.9.0 的正弦脉冲振动整体替换为**每条独立的双八度平滑随机噪声**，并把竖条/基线渲染从硬边像素矩形升级为渐变+柔光+圆角收头。

## 一、常驻随机振动（根治"定格不动"）

### 根因（v2.9.1 为什么观感是"停在那里不动"）
- v2.9.0 振动模型是**相位步进正弦**：`sin(2π·t·speed + 簇相位 + 条序号×0.85)` —— 全簇竖条按规则行波整体轻晃，不是每条独立随机起伏；
- 叠加项 `oscUp = ampPx·bell·pulse` 是像素级常量小项，响度恒定时竖条高度基本不动；
- 两者叠加：响度不变 → 条高近乎定格，只有 sine 的微弱整体波动。

### v2.9.2 新模型（SoundPrintOscillator.wobble 常驻抖动）
- **每条竖条独立的双八度平滑值噪声** wobble ∈ [-1, 1]：慢八度（0.16s 重定位）做主体漂移 + 快八度（0.065s）做微颤，smoothstep 插值**无级连续、永不瞬移**；哈希决定于（簇相位, 条序号, 时间格），纯函数无跨帧状态；
- 竖条高度 = 基础高度 × (1 + 抖动幅度 × wobble)——**每条独立地随机上下收缩与拉长**（可缩可伸双向），即使声源响度完全不变也持续"活着"，观感如实时频谱分析；
- 抖动幅度 = 条高比例：基础 **±10%**（最弱活声纹也常驻微动）→ 满强度 **±26%**，按 `响度×距离衰减×叠加增益` 缩放——**越响越大、越近越大**（"幅度稍小"档位）；
- **只有声音消失才渐弱**：能量归零后按 v2.9.1 linger 指数收尾模型整体收拢归零，行为不变；
- 聚合分簇 / 模拟器 / 设置界面预览三路管线完全一致（纯时间+种子函数，无状态分歧）。

### 配置变化
| 键 | v2.9.1 | v2.9.2 | 说明 |
|---|---|---|---|
| animation.oscillate | 声纹条振动开关 | **常驻随机振动**开关 | 语义升级，默认仍为 true；关闭后声纹条静止（纯响度高度） |
| animation.osc_speed_hz | 振动频率 3.5Hz | 振动节奏 3.5Hz | 3.5 = 出厂节奏基准（缩放抖动时间轴），范围 0.5–8 不变 |
| animation.osc_amp_min/max_px | 声纹条最小/最大振幅 | **方向箭头**伸展振幅 | 不再作用于声纹条；语言键改"箭头最小/最大伸展"（en: Arrow min/max reach） |
| （其余） | — | — | 无新增键；旧配置值全部兼容不改写 |

声纹条抖动幅度（±10%~±26%）为模型内建档位（"幅度稍小"反馈直接固化），不暴露配置面。

## 二、现代风格渲染（去像素化）

| 元素 | v2.9.1（像素感来源） | v2.9.2（现代风） |
|---|---|---|
| 竖条本体 | 硬边纯色矩形 `fill()` | 垂直渐变 `fillGradient()`：基线侧实色、尖端渐透（30% 透明度过渡） |
| 竖条光晕 | 上下各 0.5px 阶梯硬光晕（像素台阶感） | 整体 1px 外扩柔光（13% 低透明度，无台阶） |
| 竖条尖端 | 平头硬切 | 宽 ≥3px 几何圆角收头；窄条（2px）尖端行半透明柔化（55%） |
| 基线白线 | 两端硬切 + 0.5px 阶梯光晕 | 两端 12px 渐隐（30%→100%→30%）+ 1px 底部柔影（12%） |
| 几何布局 | — | **零改动**：条数/条宽/间距/最大高度/位置预设全部保持（不破坏 v2.9.1 位置调优） |

## 复测清单

1. 装入 v2.9.2（配置兼容，无需删旧配置；`/soundprint reset` 可一键回默认）；
2. **常驻感**：让生物/玩家在半径内持续走动——竖条应每条独立地随机收缩拉长、永不定格，即使响度不变；
3. **响度联动**：声源越近/越响，抖动幅度越大（±10% 微动 → ±26% 明显）；枪声比脚步更"炸"；
4. **收尾**：声音停止后整体按收尾衰减渐弱收拢（约 1 秒内），无声不残留白条（v2.9.1 行为不变）；
5. **现代观感**：竖条有渐变（下实上透）、尖端圆角、外围柔光；基线两端渐隐——不再有硬边像素块感；
6. 设置界面动画页"常驻随机振动"开关 + "振动节奏"滑条实时生效（预览箱同款抖动）；"箭头最小/最大伸展"只影响垂直方向箭头；
7. `/soundprint sim on` 模拟器应同样呈现每条独立抖动。
