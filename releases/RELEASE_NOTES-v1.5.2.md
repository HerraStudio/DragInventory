# HERRA 方位罗盘 v1.5.2

> Minecraft 1.21.1 · NeoForge 21.1.251 · 无需服务端

## 本轮主题：交互可靠性与标点同步

实测反馈集中修复：设置界面"点了没反应/连跳/回跳"、开关视觉异常、颜色条不能拖动、
敌人标点不消失、方位条图标与实际标点不一致；并新增拖拽定位、快捷对齐、
屏宽占比预设、刻度密度自适应、三套菜单主题与全套动效打磨。

## 修复（实测反馈）

- **配置保存竞态（根因级修复）**：NeoForge 写盘后，FML 文件监视线程会异步重读文件并
  整体替换内存配置；若在"落盘 → 重载完成"窗口内继续修改，新值会被旧文件内容覆盖——
  这就是"开关点了没生效""配色跳到下一个又跳回来""左右键连跳两下"的真相。
  现在 `CompassConfig` 引入写前日志（journal），配置重载事件触发对账：未持久化的值
  自动重放并再次落盘，两轮内收敛。开关、配色循环器、滑杆、恢复默认全部受益。
- **开关滑块动画反向**：OFF 分支插值参数写反，导致 ON/OFF 滑块都停在右侧、
  视觉上"开关显示不正确"。已修正并升级为 120ms 弹性缓动（轻微过冲）。
- **HSL 颜色条无法连续拖动**：旧版只处理了按下，没实现拖拽路由。现在按住色相/
  饱和度/明度条即可连续拉动调色，拖拽中的分量手柄与数值高亮。
- **滑杆拖拽几何漂移**：开始拖动后轨道宽度比点击时宽 13px（重置按钮列），
  数值瞬间跳变；已统一几何。行渲染与点击路由的宽度也完全对齐。
- **敌人标点不同步消失**：两个独立来源——(1) 测试标点永不过期（60 秒后仍残留在
  方位条上，与战术标点 60s 生命周期不一致）；(2) 战术标点桥接未跟随 3D 标点的
  显示条件。现在测试标点与战术标点同为 60 秒过期；桥接复刻 3D 标点的
  `canInput` 可见性条件并逐标点复检 `valid()`——3D 标点消失，方位条同步消失。
- **方位条图标与实际标点一致**：方位条下的标记改为直接使用实际战术标点的图标与
  配色——普通点 = 白色菱形（45° 方块 + 暗色衬底）、敌人点 = 红色 #FF4949 感叹号、
  掉落物 = 物品贴图本体（掉的是钻石就显示钻石）。设置界面预览同步更新。
- 预览盒缩放溢出：大缩放或超宽条带会把预览画出盒子；预览现在按可用宽高自适应缩放。

## 新功能

- **全屏拖拽定位**（布局页签 → "拖拽定位"）：直接用鼠标拖动真实 HUD 到想要的位置，
  虚线"蚂蚁线"高亮框 + 实时坐标读数；滚轮顺手调宽度，右键/Esc/完成按钮退出。
  定位模式下跳过原版菜单模糊，HUD 全程清晰可见。
- **快捷对齐**：水平居中 / 顶部对齐 / 垂直居中 / 底部对齐，一键到位。
- **屏宽占比预设**：1/4、1/3、1/2、2/3 屏宽四档按钮；条带宽度上限 520 → 960
  （滑杆与 `/compass width` 指令同步扩展），宽度显示附屏宽百分比。
- **刻度密度自适应**：条带拉宽/放大后，刻度与数字按"参照密度"自动加密
  （用户在默认宽度下选定的视觉密度保持不变——特意设置的大步长不会被强制加密，
  窄条带也绝不稀释）。字体与刻度长度不变，只增加数量，拉长后视觉不违和。
- **三套菜单主题**（外观页签）：琥珀（默认）/ 青蓝 / 猩红，面板底色与强调色成套更换。

## 动效与视觉打磨

- 面板关闭动画：130ms 缩小淡出后退出（原来瞬断）。
- 页签指示条：底部高亮线从旧页签平滑滑到新页签。
- 行悬停：左侧主题色高亮条 + 底色；按钮按压 220ms 主题色闪光。
- 滑杆手柄拖拽时放大 1px + 数值提亮；开关弹性缓动（见上）。
