# Drag Inventory 2.0.0

本次大版本增加工厂战术地图，将地表、室内楼层和战术标记集中到全屏地图中。沿用已有枪械 HUD、方位条、物品拖拽、生命值与体力功能。

- 按 M 打开地图：深色地表与屋顶总览、半透明侧栏、分类图标、比例尺和操作提示。
- 可切换室内楼层切片，自动跟随楼层或手动选择附近楼层。
- 支持左键拖动、滚轮以鼠标为中心缩放、空格定位，以及右键/中键地图标点。
- 左侧显示标点距离和剩余时间，点击条目定位；右侧图例筛选标点类型，Shift 显示/隐藏图例。
- 地图标点与世界 HUD 共用 5 个名额及 60 秒生命周期。仅本机显示，不向队友广播。
- 底图分帧采样生成动态纹理；修复地图朝向、菜单模糊和 GUI 比例变化后的交互。

## 安装

Minecraft 1.21.1、NeoForge 21.1.251、Java 21；客户端需要 LDLib2 2.2.40。退出游戏并移除旧版 Drag Inventory JAR，再安装 `drag-inventory-1.21.1-neoforge-2.0.0.jar`。联机时客户端和服务端使用一致版本。GWO 为可选配套模组。

## 验证与范围

75 项单元测试及正式构建通过。地图改版已在隔离客户端验证总览、切片、拖动缩放、标点、侧栏输入、GUI 比例调整、图例隐藏和重开。

底图来自当前客户端已加载区块，未加载区域不能标记；室内切片沿用静态工厂几何缓存，暂不实时反映已缓存位置的建造/拆除。截图中的测试建筑不随模组加入用户世界。
