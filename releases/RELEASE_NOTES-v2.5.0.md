# Drag Inventory 2.5.0 —— 彩色战术地图

战术地图底图改为彩色：按方块的真实颜色实时采样成图（对标 Xaero 世界地图），保留方块像素结构，走到哪里、加载到哪里就画到哪里。房门与楼梯保留战术强调色，深坑与阻挡区域自动压暗，真实外观与战术信息兼得。

滤镜改为预设制：视觉页六选一——关闭（彩色）/ 三角洲 / 塔科夫 / 暗区突围 / Apex / PUBG，默认彩色不滤镜；/map filter 指令同步同一份预设，切换后整图立即重烤。

大地图默认清屏模式：只显示地图、玩家与标点，按 H 或右侧眼睛按钮唤出完整界面；清屏时右下角小字提示按键，视线不被界面元素干扰。

界面精简：图标按钮从 24 缩小到 18 像素；左侧面板移除，图例与标点管理合并到右侧工具栏第一个按钮的弹窗；完整操作说明缩小后移到右下角。

三种地图标点：地图右键可放地点/敌情/物资三类，弹窗选类型或数字键 1/2/3 切换，C 键一键清除全部标点——大地图内或游戏内按都有效。

左上角常驻小地图：方形，跟随所在楼层，深色边框、四角青绿角标与北向指示，玩家箭头随朝向旋转；菜单可开关，缩放 0.5~4.0、尺寸 64~256 可调。小地图下方显示“对局还有 10:00 结束”占位计时——对局系统上线后经 MapMatchTimer 接口自动接入真实剩余时间。

修复一批设置不生效：透明度滑条现在真正生效（低不透明度可透出游戏世界，配合未探索区透明化）；/map off 现在真正关闭地图（M 键与小地图一并关闭，/map on 恢复）；/map floor 与设置界面手动楼层不再被当前层覆盖；显示层自动跟随玩家高度（上下楼梯防抖）；标点风格、跟随玩家、层高跨度等既往“存了不用”的配置全部接线生效。

指令调整：/map 与 /m 无参现在直接打开大地图（设置界面改由 /map gui 或工具栏设置键打开）；新增 /map filter <预设>、/map minimap on|off|zoom|size、/map marker ping <类型>|show <on|off>；移除 /map contrast|brightness|saturation（滤镜改为预设制）；/map info 汇总更新为九项。

错误修正（2.5.0 重发）：从 2.4.0 升级时自动迁移旧配置文件——旧版 /map off 留下的 "enabled = false" 在新版本接线生效后会让 M 键与小地图静默失效（表现为"地图全没了"），现在升级安装会自动把它复位为开启，并随迁移清理全部旧键；地图处于关闭状态时按 M 键不再毫无反应，动作栏会提示 "输入 /map on 开启"；/map off 的反馈文案补全了恢复方式；小地图 HUD 层新增渲染异常保护——即使小地图渲染出现异常，也只会停用小地图自身并在日志记录原因，不再波及游戏与其它 HUD。
