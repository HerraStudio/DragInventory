# Drag Inventory 2.7.0 —— 声纹 HUD + HERRA 统一设置入口

本版两项交付：①全新**声纹 HUD**（Soundprint）——方位条正下方的声音可视化条带，参考三角洲行动的声纹视觉语言（视觉规范经参考图像素级分析定稿）；②**HERRA 统一设置入口**——/herra 主指令 + 主 GUI + 模块注册 API，把本模组全部七个 HUD 模块收进一个入口，并向未来 HERRA 模组开放。

功能一——声纹 HUD（独立模块，零修改现有任何 HUD 代码）：

- **形态**：方位条正下方一条水平基准线（贴方位条底边），声源方位处向上向下各展开一排竖条，高度呈钟形包络（中心最高向两侧递减）；视觉与方位条战术像素风同语言。
- **脚步声 = 战术白，枪声 = 攻击红**：枪声的声纹更高、条更宽更密实，威胁感一眼可辨；颜色可配置覆盖。
- **检测半径默认 20 米**（4~64 可调）：采集走客户端 PlaySoundEvent——**玩家听得到才显示**，与服务器授权天然一致，零额外网络包、零作弊面。
- **与方位条逐像素同步**：声纹水平位置与方位条刻度同角度映射（同款临界阻尼弹簧、相同的目标源与刚度），转动视角时声纹与刻度一起平滑滑动，无取整阶梯；视野外的声源渐隐消失。
- **垂直偏移联动 + 无杆箭头**：声源在楼上 / 楼下时上下两排不对称增强（上方声源上排变长、下方声源下排变长），并在声纹外侧出现无杆 V 形箭头指向上 / 下（参考图 2 的箭头语言）；水平方向声源无箭头。
- **距离衰减**：平方根曲线 + 远端保底——近处脚步声纹高而醒目，20 米边缘仍有可辨识底线，不瞬间消失。
- **同方位多声源双模式（本版用户决策）**：默认**聚合合并**（merge）——方位差小于窗口（默认 6°，可调）的声源合成一簇更大的声纹，能量 RMS 合成、方位能量加权、枪声优先定色，359° 与 1° 正确跨北合并；可切换**并排错位**（stagger）——同方位声源保持各自独立声纹，最响的居中、其余横向错开排列（参考图 3 的多簇语言）。`/herrasoundprint mode stagger` 或设置界面一键切换。
- **高级流畅动画**：出现 / 消散全部为帧率无关的临界阻尼弹簧包络——枪声瞬间冲起、快速消散，脚步温和浮现、约 2.5 秒绵柔退场（三角洲行动的节奏感）；HUD 入场有 180ms 淡入轻落。
- **跟随方位条**：默认与方位条一体显隐（方位条关闭 / F3 隐藏时声纹一并隐藏），可关闭独立显示；水平位置与宽度永远贴方位条（拖动 / 拉宽 / 换皮肤实时跟随，声纹只提供垂直间距一个位置参数）。
- **独立配置** `draginventory-soundprint-client.toml`：写前日志 + 防抖落盘 + 重载对账，与方位条同一套配置纪律（拖滑条不丢值、外部热重载即时生效）。
- **设置界面**：五页签像素风 GUI（常规 / 检测 / 多声源 / 形态 / 动画），顶部合成声场实时预览（近脚步 + 远脚步 + 楼上枪声，自动摆动），主题跟随方位条设置界面的三主题。
- **指令**：`/herrasoundprint`（别名 `/soundprint`、`/sp`）——无参开设置界面；`toggle / on / off / radius <米> / mode <merge|stagger> / reset`。
- **枪声关键字可扩展**：外部枪械模组（GWO 等）的声音 id 千差万别，默认关键字表覆盖 gun / shot / shoot / rifle / pistol / sniper / cannon / gunfire / muzzle / explosion / blast，可在配置 `gunshot_keywords` 追加，无需发版。

功能二——HERRA 统一设置入口：

- **/herra 主指令**：无参数打开 HERRA 主界面；`list` 列出全部模块与开关状态；`open <模块>` 直接打开该模块设置；`toggle <模块> [on|off]` 开关模块。
- **主 GUI**：左侧模块列表（状态点：实心 = 开、空心 = 无开关项）+ 右侧详情（描述 / 状态 / 打开设置 / 开关），像素风三主题与设置界面一致。
- **内置七模块全部接入**：方位条 / 战术地图 / 声纹三个可配置模块接真实开关与设置界面；体力条 / 快捷对齐 / 枪械 HUD / 口袋轮盘为只读占位条目（**不改这些模块任何代码**——它们目前本就没有配置系统，获得配置时替换占位实现即可）。
- **开放注册 API**：`dev.draginventory.client.herra.HerraApi.registerModule(HerraModule)`——其他 HERRA 模组注册后自动出现在 /herra 主界面与指令补全中；反射软耦合约定与 CompassApi 一致（Drag Inventory 未加载时不会被调用）。
- 各模块原有指令（/com、/map、/herrasoundprint 等）全部保留——/herra 是聚合层，不是替代层。
