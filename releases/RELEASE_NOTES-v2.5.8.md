# Drag Inventory 2.5.8 —— 玩家图标严格遵循 SVG 原图

本版一项交付：修复 v2.5.7 玩家导航箭头的三个视觉问题——立体感、中缝白线、放大锯齿。图标不再"再创作"，严格遵循用户提供的《玩家位置图标.svg》原图绘制，观感即矢量原图。

修复一——去掉立体感与白缝（零再创作）：

- v2.5.7 在图标上叠加的三处"再创作"全部移除：左半压暗 18% 的折纸明暗差（立体感来源）、中脊近白折痕亮线（白缝来源）、腹下低透明度软影。
- 现在图标就是 SVG 原图本身：纯 **#32CD32** 平面单色导航箭头（单色填充 + 同色描边），无任何明暗层次。

修复二——放大无锯齿（纹理化渲染）：

- 根因：v2.5.7 用几何三角形绘制，而 Minecraft GUI 光栅化管线**没有抗锯齿**——斜边在设备像素网格上硬切成阶梯，图标越小锯齿越明显。
- 解法：SVG 原图离线栅格化为 **256×256 抗锯齿 PNG**（形状/颜色/画布零修改，主色经像素级校验精确为 #32CD32）打包进 jar；运行时上传 GPU 生成 **alpha 感知 mipmap 链**（盒滤波，透明边缘不发黑），统一以 **LINEAR + LINEAR_MIPMAP_LINEAR** 过滤绘制。
- 效果：任意 GUI 缩放（1x~4x）、呼吸缩放、弹性拉伸下边缘平滑如矢量——SVG 本来的观感。

其它：

- 视觉大小与 v2.5.7 一致（形状高 ≈12.5px，含描边 miter 的画布换算），不再变大。
- 全套移动动效保留（partialTick 插值移动、120ms 平滑转向、弹性拉伸、渐隐尾迹、静止呼吸、断流保护），残影同享原图纹理。
- 实现细节：`NativeImage.upload` 会把纹理过滤重置为 NEAREST，必须全部 mip 层上传完毕后再统一 `setFilter(true, true)`；纹理懒注册于首次渲染（渲染线程），资源缺失时回退紫黑缺失纹理可在游戏内一眼定位。
- 新增 `PlayerMarkerTexture` 纹理类与资源守卫测试（PNG 存在性 / 256×256 / alpha 通道 / 主色 #32CD32 像素级断言），全套 **179 用例 0 失败 0 错误**。

适配说明：纯客户端变更，无配置改动。适用：Minecraft Java 1.21.1 + NeoForge 21.1.251 + LDLib2 2.2.40（或 2.2.41），Java 21。直接替换 mods 内旧版 JAR 即可。
