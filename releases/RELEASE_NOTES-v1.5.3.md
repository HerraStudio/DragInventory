# HERRA 方位条 HUD v1.5.3

视觉修复三连：方位条字母遮数字、菜单翻页图层越界、预览演示居中与防溢出。
本版本全部为修复与视觉打磨，无配置格式变化，直接替换 jar 即可。

## 修复

### 1. 次方位字母遮挡角度数字（五套皮肤通用）

- **现象**：Apex 主题下"东北"等大号次方位字与旁边的度数（30/60…）横向重叠，
  字母画在数字上层，把度数挡住；视野范围调大（每度像素变少）或密度自适应
  加密数字时尤其明显。
- **根因**：所有皮肤的方位字与数字共用同一底基线，间距不足时必然横向相撞，
  而渲染顺序是"数字先画、字母后画"→ 字母永远压在数字上。
- **修复**：`CompassStyle` 新增通用碰撞检测 `numberOverlapsLetter()`——按两侧
  最近 45° 倍数字母的**实测文字宽度**（含中文双字标签"东北"、CARDINAL_SCALE
  缩放与发光放大余量）判定，重叠时跳过该数字（该位置细刻度保留，仍有方位指示）。
  五套皮肤（delta/pubg/apex/battlefield/warzone）全部接入，各皮肤传入自己的
  字母/数字缩放参数。
- **零行为变化保证**：默认配置（240px 条带 / 120° 视野 / 15° 步长）下间距充裕，
  碰撞不触发，观感与 v1.5.2 完全一致；仅在真正会重叠的配置组合下生效。
- 关闭"显示次方位/基数方位"后对应字母位不参与碰撞判定（字母都没画，数字不冤枉跳过）。

### 2. 指令菜单子选项翻动时盖住页签（图层/剪裁越界）

- **现象**：滚动或翻页时，部分滚出内容区的子选项行（"刻度间隔"标签、
  循环选择的左右箭头、开关等）画到了页签栏上，盖住"外观/显示"等主选项；
  小窗口（GUI 缩放较大、内容区需要滚动）下普遍存在。
- **根因**：内容区只有"底部越界跳过"守卫，**顶部完全敞开**——上缘半滚出的行
  会原样渲染到内容区之外（页签栏、预览盒上）；且内容区画在页签栏之后，图层更高。
- **修复**：内容区整体套一层 `enableScissor` 剪裁（绝对 GUI 坐标域，与姿态变换
  无关；面板开合缩放围绕中心只向内收，不会被误裁）。翻页上滑的 +4px 位移被底部
  剪裁线截住，行呈现为"从页脚下缘滑入"的标准滚动观感；滚出顶部的行被精确裁掉，
  再也不可能压到页签栏。
- 顺带优化：部分可见的行从"整行消失"改为"照常渲染、按剪裁线平滑截断"——
  滚动时行是滑出视口的，不再凭空消失（旧版底部守卫会让半滚出的行整行空白）。

### 3. 菜单内方位 UI 演示：始终居中 + 绝不溢出演示框

- **现象**：调整宽度/缩放/皮肤时，演示条带会漂出演示盒（调宽到 960px 时甚至
  整条滑到盒子右侧之外），或压住底部的摆动按钮/朝向滑杆；位置也不居中。
- **根因（三处叠加）**：
  1. 演示缩放水平锚点在条带中心，而定位按"缩放后宽度"算左上角 → 水平漂移；
  2. 垂直缩放锚点在屏幕原点 y=0（HUD 布局语义）→ fitScale < 1 时条带整体上漂；
  3. 可用高度未扣除底部控件带（摆动按钮/滑杆/提示文字）→ 高皮肤重叠控件。
- **修复**：
  - `renderStandalone` 预览缩放改为**以条带自身中心为锚**（水平 + 垂直双轴），
    HUD 路径的 y=0 锚点保持不变（全屏拖拽定位的坐标换算依赖它）；
  - 预览几何按演示盒**可用区**（扣除底部控件带 14px）计算，条带水平 + 垂直
    **始终居中于可用区**，与宽度/缩放/皮肤组合无关；
  - 演示盒内套剪裁：惯性倾斜、超大方位字（CARDINAL_SCALE 2.0）、边缘宽中文
    标签等极端调整只会在盒内被裁掉，**绝不溢出演示框**。
