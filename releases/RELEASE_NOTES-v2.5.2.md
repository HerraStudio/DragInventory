# Drag Inventory 2.5.2 —— 小地图修复与楼层自动跟随

本版针对 2.5.1 实测反馈做出七项改进，重点修复小地图消失与错误材质，并将楼层调整为恒定自动跟随。

修复一（最重要）——小地图消失与错误材质：小地图、大地图、设置预览三个瓦片渲染实例此前会生成同名的纹理资源，NeoForge 对重复纹理的注册会直接关闭并释放旧纹理——表现为小地图渲染异常后在本客户端会话内永久消失（重进存档、在设置里重新打开开关都无效），或小地图画面变成错误材质。本版让每个瓦片纹理的全局编号永不重复，三个实例互不干扰；同时把小地图的异常保护从"本会话永久停用"改为可恢复：出错后暂停 10 秒自动重试（连续 3 次才彻底停用），且切换世界/存档后自动复位。进入新存档时楼层缓存也一并重置，不再继承旧世界的层。

修复二——设置 GUI 里调节小地图大小：行为页重排，"小地图开关 / 缩放 / 尺寸"三行排在前面，尺寸滑条（64~256 像素）完整可见、即时生效（此前最后一行滑条与底部按钮重叠、且小地图一旦熔断后调节无效果）。指令 /map minimap size 与之等效。

改进三——图例与标点管理弹窗从画布左侧伸出：位置对标 2.4.0 的左侧面板（左上角锚定），但占位更小（约 210×240 的浮出面板，地图仍近乎满屏），开启时带 180 毫秒的滑入动画。

改进四——楼层恒定自动跟随玩家：移除了手动调整显示层的全部入口（右侧工具栏的上层/下层按钮、PgUp/PgDn/Home 键、设置页的手动楼层、/map floor 系列指令与 auto_floor/manual_floor_y 配置项），活动楼层永远跟随你实际所在的楼层；自动层带死区+迟滞双防抖（沿用 2.5.1），换层有顶部提示。小地图与大地图现在共享同一份楼层目录、始终显示同一层。

改进五——快捷键全面主键盘化（照顾小配列键盘玩家）：地图内只使用 M / Esc / H / C / 1 / 2 / 3 / 空格 / 鼠标滚轮，全部是主键盘核心键区可直接打出的键——不依赖数字小键盘（小键盘数字不响应，1/2/3 以主键盘为准）、不依赖 PageUp/PageDown/Home 等扩展键区。已移除的 Home"自动追踪"等键位无需替代（对应功能已随手动层一并移除）。

改进六——快捷键提示补全：大地图底部说明现在完整列出"1/2/3 标点类型"切换（此前只能误触发现），按 H/C 改键后说明中的键名会动态跟随。

适配说明：旧配置文件里的 auto_floor / manual_floor_y 两个键会在加载本版后被自动清理，无需手动改动。

适用：Minecraft Java 1.21.1 + NeoForge 21.1.251 + LDLib2 2.2.40（或 2.2.41），Java 21。直接替换 mods 内旧版 JAR 即可。
