# Drag Inventory v2.9.5 — 用户实测预设固化为出厂默认 + 方向箭头双 bug 根治

本版两项交付：①用户对 v2.9.4 整体满意后**回传配置文件**，六项调校值**原样固化为新出厂预设**（老配置一次性收敛，自定值保留）；②根治方向箭头自 v2.9.2 起潜伏的两个方向性 bug——**声源在下方时箭头朝上指**（方向反转）、**声源在上方时上方无箭头**（落点陷条 + 显形阈值偏高）。

## 一、用户预设固化（根治"配置还有些不准确，直接把我调好的发你"）

用户回传 `draginventory-soundprint-client.toml`，与 v2.9.4 出厂默认逐项对比，六项差异原样进入代码默认值：

| 参数 | v2.9.4 默认 | **v2.9.5 默认** | 说明 |
|---|---|---|---|
| `bar_count`（单簇条数） | 14 | **21** | 更细更密的声纹条，单簇宽 67px→81px |
| `bar_width`（条宽） | 2 | **1** | 配合 21 条形成高频谱观感 |
| `osc_speed_hz`（振动节奏） | 3.5 | **5.6** | 律动加快 60% |
| `osc_amp_max_px`（箭头伸展上限） | 9 | **24** | 拉满上限，箭头伸展更醒目 |
| `offset_y_px`（纵向位置） | -174 | **-143** | 整体下移 31px，更贴近快捷栏 |
| `detect_own_gunshots`（自枪声检测） | true | **false** | 实战中自己开枪不该点亮声纹；测试时在设置里打开即可 |

- 其余参数（max_height 30 / opacity 1.0 / scale 1.0 / spacing 0 / preset bottom_center / width 380 / offset_x 0 等）与 v2.9.4 一致，零改动；
- **v295_retuned 一次性迁移**（SoundPrintConfigEvents.retuneV295Defaults，v2.8.0 retune 纪律）：只动**仍是旧默认值**的项，用户自定值永远保留；回传用户本人的文件已全部等于新默认，迁移只落标记；
- 设置页脚"恢复默认"或 `/soundprint reset` 一键回到本套预设。

## 二、箭头方向反转根治（根治"声源在下方时，箭头出现在下方声纹但朝上指"）

### 根因（自 v2.9.2 潜伏）
`drawVArrow` 逐行绘制自顶向下（`y = cy - h + i`，i=0 为顶行），臂展公式 `spread = up ? 1.0F - t : t` **三元写反**：
- `up=true`：顶行最宽、底行收尖 → 画出来是**下尖 "v"**（本意上尖 "^"）；
- `up=false`：顶行收尖、底行最宽 → 画出来是**上尖 "^"**（本意下尖 "v"）。

结果：**所有箭头都指向声源的反方向**。声源在下方走 `up=false` 分支 → 下方位正确但箭头朝上指，与实测完全吻合。v2.9.2~v2.9.3 期间未被发现，是因为垂直声源场景在 v2.9.4 振幅放大后才高频进入实测视野。

### v2.9.5 修复
- 臂展逻辑抽出为**纯函数** `SoundPrintEnvelope.arrowRowSpread(up, t)`：上箭头尖在顶、臂在底（spread 随 t 增大），下箭头镜像（spread 随 t 减小），越界 t 钳制 [0,1]；
- 渲染器 `drawVArrow` 改调该函数，并清理原 up/down 完全相同的 y 三元；
- **EnvelopeTest 新增 1 例方向回归锁定**（上箭头顶窄底宽 / 下箭头镜像 / 越界钳制），该 bug 从此有单测兜底。

## 三、上方箭头消失根治（根治"声源在上方时，上方没有小箭头"）

### 根因（双因叠加）
- **(a) 箭头落点陷进白条堆**：v2.9.4 落点公式 `reach = heightBase×0.92 + 3.5 + amp×0.6` 基于能量前基底，但**垂直不对称加成（最高 1.75x）会把声源侧的条拉到远超 heightBase 的高度**（顶棚 capSide 才是上限）——中低能量时 reach 估算远小于实际条高，箭头画进了同色白条堆里，直接被吃掉；
- **(b) 显形死区偏高**：`arrowStrength` 死区 0.22（声源高/低约 0.9 格才显形）+ 0.05 门槛，浅高差场景（平台上方 1 格）箭头完全不出。

### v2.9.5 修复
- **锚定实际条高**：drawCluster 逐条追踪本簇实际绘制的最高条 `maxUp` / `maxDown`（≥1px 才计入），箭头落点 = 基线 ± 实际最高条 ± 固定间隙 2px ± osc_amp 伸展（`ampPx×0.6`，越响越近伸得越远，用户调的 24px 上限在这里生效）——**箭头永远在条堆外侧清晰可见**；
- **死区 0.22→0.15**：声源高/低约 0.6 格即开始淡入，满强度仍 0.65（约 2.6 格）；
- 上/下两侧公式对称，垂直交战双向可读。

## 四、复测清单（建议覆盖场景）

1. **恢复默认核对**：设置页脚"恢复默认"→ 逐项核对六值（条数 21 / 条宽 1 / 节奏 5.6 / 伸展 24 / Y -143 / 自枪声关）；
2. **下方声源箭头**：楼下/地下室脚步或枪声 → 下方箭头**朝下指**（v2.9.4 是朝上）；
3. **上方声源箭头**：楼上/高台脚步或枪声 → **上方出现朝上指箭头**（v2.9.4 完全无箭头）；
4. **浅高差**：声源只高/低 1 格左右 → 箭头开始淡入可见（v2.9.4 完全不出）；
5. **箭头随响度伸展**：近处大声源箭头离条堆更远（osc_amp_max 24 生效）；
6. **自枪声**：默认自己开枪不再点亮声纹；设置里打开 detect_own_gunshots 后恢复测试行为（投视线前方 4 米、条带正中）；
7. **升级收敛**：用 v2.9.4 默认配置直接升级 → 六项自动收敛到新预设；改过其中某项（如 bar_count=18）→ 该项保留。
