# Drag Inventory v1.4.9 — HERRA 方位条 HUD

> Minecraft 1.21.1 · NeoForge 21.1.251 · 依赖 LDLib2 2.2.40+
> 安装：将 `drag-inventory-1.21.1-neoforge-1.4.9.jar` 放入 `mods/` 目录。

## 本版本亮点：三角洲行动风格顶部方位条

- **顶部中央极简方位条**：中间高亮当前朝向数字，两侧滚动方位文字与刻度；临界阻尼弹簧平滑（359°↔0° 跨零不甩动）。
- **4 皮肤 × 6 配色**：minimal / glass / tactical / neon × aurora / frost / amber / crimson / violet / slate，颜色可逐项覆盖，标点色自动与主题色撞色规避。
- **标点联动**：只读接入中键战术标点体系；**形状分型**（敌=菱形、点=三角、物=方块、死=X）；屏外标点边缘吸附 + 方向箭头；文字标签与距离合成一行。
- **死亡标点**：死亡自动标记红色 X，导航回落包点，靠近 8 米自动消失。
- **`/compass` 指令 + 图形化设置界面**：18 个子指令全覆盖，设置界面实时预览。
- **按键绑定**：选项 → 控制 → Drag Inventory → "开关方位条"（默认未绑定）。
- **零侵入**：独立 GUI 层注册，不修改现有快捷栏 / 体力血条 / 枪械 HUD 的任何代码。
- **联动 API**：`CompassApi` 供其他 HERRA 模组读取朝向、注册标点、监听方位事件。
