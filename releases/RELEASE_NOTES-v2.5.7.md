# Drag Inventory 2.5.7 —— 导航箭头图标 · 动效优化 · 联动 API

本版三项交付：玩家位置图标依用户提供的 SVG 设计稿换为导航箭头并整体缩小；移动动效做了一轮"丝滑化"优化；并正式公开战术地图联动 API（标点联动 + 对局结束倒计时为核心，配套 wiki 接口文档），供对局系统/联动模组接入。

改进一——玩家图标换导航箭头（小地图 / 大地图 / 设置预览三处同步）：

- 依用户上传的《玩家位置图标.svg》重做：单尖头四边形导航箭头（尖头顶点 + 双后角 + 后缘凹口），几何等比缩放自设计稿 viewBox。
- 配色取设计稿原色 **#32CD32**（右半翼），左半翼同色压暗 18% 模拟折纸受光，中脊近白折痕线，腹下低透明度软影——延续 v2.5.6 的现代极简绘制语言。
- **整体缩小约 22%**：整体高 12.5px（v2.5.6 纸飞机为 16px），应用户"图标不要太大，小一点"的反馈。

改进二——移动动效优化（丝滑化）：

- 插值移动：三处渲染入口改喂 partialTick 插值坐标——图标与尾迹位置消除 20Hz tick 台阶与整数取整台阶（亚像素连续移动），任意缩放下匀速平滑。
- 速度估计连续化：输入插值后速度不再"边界尖峰/帧间零速"锯齿，弹性拉伸与尾迹强度更稳（临界速度不再闪烁）。
- 更跟手：平滑时间常数 140ms → 120ms（输入噪声降低后滤波更轻），转向与拉伸响应更快。
- 动效全家桶保留：平滑转向 / 弹性形变 / 渐隐尾迹 / 静止呼吸 / 断流保护，行为口径不变。

改进三——联动 API 正式公开（`dev.draginventory.client.map.TacticalMapApi` 统一门面）：

- **外部标点**：稳定 ID + 自定义存活时长（最长 24 小时）+ 独立 16 名额（不占玩家手动 5 名额）；同 ID 原地更新幂等；放置后自动进入大地图/小地图/世界 HUD/方位条全部四个视图。
- **标点事件监听**：ADDED / REMOVED / EXPIRED / CLEARED 四类事件推送（如"玩家放敌情标点 → 转发队友"），任意线程注册、客户端线程回调、逐监听器异常隔离。
- **对局结束倒计时扩展**：加时/减时（越过剩余立即归零）、截止时刻对表、Provider 自省、"对局结束"沿回调（仅剩余从 > 0 首次到达 0 触发——停止 off、重复零位、重新开始均不误触发，延迟 ≤1 拍）；Provider 接管机制（v2.5.5 预留）正式形成稳定接口。
- **POI 图标**：注册/注销（撤离点/首领/事件等预设图标渲染位）。
- **地图控制**：编程式打开大地图/设置界面、开合状态查询。
- `TacticalMarker` 升级逐标点 TTL（玩家手动标点仍默认 60 秒，行为不变）。
- **接口详细文档**：wiki 新增《战术地图API》——含快速接入、标点联动与倒计时详解（参数表/事件触发表/线程约束/渲染联动拓扑）、完整联动模组骨架示例、兼容性与版本政策。

质量：新增 9 组单测断言（外部标点容量控制 4 + 计时扩展 5），全套 **177 用例 0 失败 0 错误**；先收集后移除再触发事件的模式杜绝监听器重入并发修改；玩家侧默认行为零变化（两池隔离、TTL 默认值口径不变）。

适配说明：纯客户端变更，无配置改动，玩家侧无行为变化。适用：Minecraft Java 1.21.1 + NeoForge 21.1.251 + LDLib2 2.2.40（或 2.2.41），Java 21。直接替换 mods 内旧版 JAR 即可。联动开发指引见仓库 `wiki/战术地图API.md`。
