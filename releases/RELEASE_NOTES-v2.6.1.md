# Drag Inventory 2.6.1 —— 方位条默认预设重调 + 倒计时归零字样停留后消失

本版两项交付，均来自用户实机反馈：①方位条（罗盘）出厂默认观感不佳，按用户实测调优的新预设重调；②对局倒计时归零后的"对局已结束"字样不再常驻，停留约 2.5 秒后整行消失。

功能一——方位条出厂预设重调：

- **默认皮肤 delta → apex**：Apex 皮肤为悬浮式布局（无条带无读数框、两端 Alpha 渐隐），视觉上最"轻"的一套——不遮挡地图与其他 HUD。
- **顶部对齐**：`offset_y` 6 → 0，与设置界面快捷对齐"贴顶"同值；水平居中 `offset_x = 0` 不变（新旧默认相同）。
- **条宽 240 → 427**：640 GUI 宽（1080p / 缩放 3 的主流配置）下"屏宽占比 2/3"预设按钮的换算值，即用户实测调优的宽度；整体缩放 1.0 不变。
- **老玩家无感升级**：仿 `minimap.size_retuned` / `behavior.zoom_retuned` 先例的**一次性收敛**——升级后首次加载时逐项检测，仅把"仍是旧默认值"的项换成新默认（`Retuned compass *` 日志逐条可见）；玩家自定过的项一律保留；置位 `general.defaults_retuned` 标记并落盘，此后玩家改回旧值的选择被永久尊重。全新安装直接以新默认生成配置文件。
- 五套皮肤（三角洲/绝地求生/Apex/战地/使命召唤）与六组配色全部保留，`/compass style delta` 随时可切回。

功能二——对局倒计时归零字样停留后消失：

- 归零后的红色"**对局已结束**"**停留约 2.5 秒**（用户给定 2~3 秒区间取中值）后**整行消失**，不再常驻遮挡小地图下方视野。
- **重新开始计时会重新出现**：结束时刻由既有结束沿检测顺带记录（`MapMatchTimer.endedAtMillis`），恢复 > 0（加时/重开）自动复位，下次归零重新走 2.5 秒停留。
- **`/map timer off` 隐藏不是结束**：主动关闭一并复位停留计时，下次开启正常显示。
- 计时中的颜色（醒目金 / 末 60 秒红）与全部动效（秒位跳变脉冲、冒号呼吸、紧急闪烁）不变。

其它：

- 新增配置标记 `compass.general.defaults_retuned`（默认 false，收敛后 true）；`MapMatchTimer.endedAtMillis()` 同步公开为联动 API 自省口（对局系统可查询归零时刻）。
- 全套 **181 用例 0 失败 0 错误**（新增 `endedAtMillisLifecycle` 生命周期用例：计时态 0 → 结束沿记录 → 零位不重复记录 → 重新开始复位 → stop 复位）。
- 实机复测要点：老配置升级后日志出现 `Retuned compass *` 三条且实际观感切换（apex/贴顶/427 宽）；自定过某项的玩家该项不被覆盖；归零后"对局已结束"约 2.5 秒消失、`/map timer 5` 重开后又正常显示；`/map timer off` 后再开启计时正常。

适配说明：纯客户端变更；新增一个可选配置标记键（默认 false，不迁移老值）。适用：Minecraft Java 1.21.1 + NeoForge 21.1.251 + LDLib2 2.2.40（或 2.2.41），Java 21。直接替换 mods 内旧版 JAR 即可。
