# Drag Inventory 2.4.0

战术地图底图重做为按真实地形动态绘制：世界按 64×64 格切成瓦片渐进烘焙，LRU 缓存自动淘汰，读取已加载区块的方块数据实时成图。地图不再局限于固定工厂区域，任何地图、走到哪里画到哪里。

每格方块归入九类战术语义——墙体、地面、边界、楼梯、房门、水体、阻挡、装饰——高对比配色，浅白建筑对标现代战术地图风格，同时保留方块像素质感。

楼层系统重做：自动跟随玩家高度，PgUp/PgDn 手动切换楼层，Home 回到自动；层高跨度与楼层扫描半径可调；上层墙体轮廓与下层地面淡显叠加，立体结构一眼可读。

HUD 布局重构：左侧全高战术面板可折叠（Shift 或箭头，198↔26 像素），收纳标点列表、类型筛选、八个图层开关与清除按钮；顶部楼层大字与楼层标签组；右侧五按钮图标工具栏；右下角缩放控件与比例尺坐标。

修复进入地图或缩放拖动后贴图错位：纹理与标点、网格统一到同一浮点坐标系，整数倍缩放启用 NEAREST 锐利采样。移除右侧图例无用的“定位”按钮（空格与工具栏均可回中）；左侧标点面板紧凑化，不再遮挡主视野。

游戏内指令 /herramap /map /m：无参打开地图设置界面，26 个子命令覆盖楼层、图层、滤镜、行为、标点全部配置，非法参数报错并列出合法值，/map info 一条消息查看当前状态。

地图设置 GUI 分五页签（楼层/图层/视觉/行为/标点），顶部迷你地图与语义色板实时预览，滑条改动即时生效并防抖落盘，与地图同套战术视觉。配置文件 draginventory-map-client.toml 五组全部可视化、指令化可调，重启恢复。

预设图标接口已预留（撤离点、首领、事件待对局系统接入），左面板保留“暂无特殊事件”占位分区。
