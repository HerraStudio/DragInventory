# Drag Inventory 2.5.6 —— 玩家图标现代化与移动动效

本版应反馈对地图的玩家位置图标做一次视觉与动效升级：像素风箭头重做为现代极简纸飞机（形制与配色不变），并补上一整套移动动效；同时移除大地图上多余的图标外框。

改进一——现代极简纸飞机（小地图 / 大地图 / 设置预览三处同步）：

- 形制与配色不变：仍是"后缘带 V 形缺口的等腰长三角形"（纸飞机），青绿主色不变——只换风格。
- 平滑几何：从 9 行像素阶梯 fill 换成三角几何绘制，斜边平滑，告别像素锯齿感。
- 折纸质感：左右翼同色系明暗差（右翼主题青绿、左翼压暗 18%）模拟受光面，中脊一条近白折痕线贯穿机头到尾缺口，机腹垫低透明度软影——现代扁平设计的"悬浮感"。

改进二——移动动效（全自动，无需配置）：

- 平滑转向：转身时图标平滑跟随（140ms 时间常数，跨 ±360° 走最短弧），急转不瞬跳。
- 弹性形变：速度感知——移动越快沿机头方向拉伸越多（最多 +30%）、横向收窄（最多 -12%），8 格/秒饱和（疾跑/骑马刚好拉满），有空气动力学感。
- 渐隐尾迹：速度超过 1.2 格/秒时身后出现两枚渐隐缩小的残影（120ms 与 260ms 前的轨迹采样），越快越明显；潜行级慢速不触发，静止即消失。
- 静止呼吸：停下后轻微呼吸（1.8% 缩放、2.4 秒周期），一动就淡出——位置精确优先，不给定位引入视觉摆动。
- 断流保护：切后台/长卡顿恢复后残影不会跳到远古位置；传送（位移 > 64 格）与换世界自动重置动效状态。

改进三——大地图去掉图标外框：玩家图标周围原有的 21×21 半透明青绿方框（视觉冗余）移除，仅保留图标本体。

质量：新增 `PlayerMarkerFX` 纯逻辑动效类（时钟注入、零 Minecraft 依赖）与 `PlayerMarkerFXTest`（角度环绕数学、指数逼近、速度收敛、尾迹采样与衰减、传送重置、同帧去重、断流保护等 15 组断言）；全套 168 用例 0 失败 0 错误。渲染路径复用项目内已验证的自定义几何绘制先例（weapon wheel 同款管线），RenderSystem 状态进出一致。

适配说明：纯客户端视觉变更，无配置改动，无行为变更。适用：Minecraft Java 1.21.1 + NeoForge 21.1.251 + LDLib2 2.2.40（或 2.2.41），Java 21。直接替换 mods 内旧版 JAR 即可。
