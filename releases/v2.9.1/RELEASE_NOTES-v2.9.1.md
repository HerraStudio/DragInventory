# Drag Inventory v2.9.1 — 声纹"活振动"重做

本版针对实测反馈三项：声纹要有"活"的振动动画、位置预设固化为出厂默认、
全局恢复默认。核心是声纹能量模型整体重做（v2.9.0 静止保持模型 → v2.9.1 实时响度模型）。

## 一、活振动动画（核心重做）

### 根因（v2.9.0 为什么"白条残留"）
- 竖条高度公式带 0.4 静态下限：`heightBase = max(0.4 + 0.6×energy)`，能量衰减到 0
  后条仍钉在约 40% 高度不动；
- 能量模型是"满能量保持 650ms → 线性淡出"：脚步间隔内整簇静止满高；
- 两者叠加 = 声音停止后一簇静止白条驻留约 2 秒，然后突然消失（40% 高度直接跳没）。

### v2.9.1 新模型（SoundPrintTracker 活能量）
- 每个声源维护**实时响度 live**：收到声音事件瞬间跳到该事件的响度，之后按
  `linger`（新语义：收尾衰减常数，默认 280ms，指数）连续衰减；
- 竖条高度**直接等于当前响度**（去掉 0.4 静态下限）——有声音就一直随响度起伏，
  脚步间隔内条随节奏"呼吸"（450ms 间隔中段约回落到峰值 45%）；
- 振动（oscillate）叠加在呼吸之上，幅度随响度×距离缩放：**越响振动越大**；
- 声音停止：条按指数连续收拢到 0（约 1~1.3s 自然收尾），基线白线同步随最响
  声源淡出——**无声后整体收掉，不残留任何白条，无突变**；
- 枪声尾速 0.6 倍（收得比脚步更干脆利落）；
- 走动续期联动新模型：走动中的实体按连续声处理，声纹保持满振动不塌。

### 配置变化
| 键 | v2.9.0 | v2.9.1 | 说明 |
|---|---|---|---|
| animation.linger_ms | 默认 650，300–1500，满能量保持窗口 | 默认 280，100–1000，指数收尾常数 | 语义重定义；旧配置值兼容不改写 |
| （其余） | — | — | 无新增键 |

GUI 动画页滑条与 /soundprint linger 指令范围同步改为 100–1000。

## 二、位置预设固化为出厂默认

| 键 | v2.9.0 默认 | v2.9.1 出厂默认 |
|---|---|---|
| position.preset | below_compass | below_compass |
| position.spacing | 2 | **4**（与方位条底边多留一档空气） |
| position.width_px | 240 | **260**（匹配 v2.8.0 拉宽后的单簇 67px） |
| position.offset_x_px | 0 | 0 |
| position.offset_y_px | 0 | 0 |

> 说明：本组值为按上轮反馈方向（拉宽 + 与方位条留距）的出厂预设。若与你
> 手上调好的那组数字不同，回我 `/soundprint status` 输出（或直接报
> preset/spacing/width/offset_x/offset_y 五个值），下一版即按你报的值固化。

## 三、全局恢复默认

- **GUI**：设置界面页脚"恢复默认"按钮（v2.9.0 已有，本版补点击音效反馈，
  全部控件即时刷新为新出厂预设）；
- **指令**：`/soundprint reset`（或 `/herrasoundprint reset`）等效；
- 恢复后即刻得到本版全部新默认（含 linger 280 与位置预设）。

## 复测清单

1. 装入 v2.9.1（**建议先删旧 `config/draginventory-soundprint-client.toml`**
   或进游戏按一次"恢复默认"，让 linger 650 → 280 生效）；
2. 走动测试：半径内有生物走动时，声纹应**持续振动不静止**，停下后约 1 秒内
   整体收拢消失，无白条残留；
3. 脚步节奏：远处脚步应能看到条随步伐"呼吸"（一亮一沉），而不是定格；
4. 枪声：比脚步收得更快更干脆；
5. 模拟器 `/soundprint sim on`：footstep 模式 420ms 节奏呼吸感明显；
6. 设置界面动画页"收尾衰减"滑条左右拉，实时感受收尾快慢（值小=收得快）；
7. 页脚"恢复默认"点击后：位置回到 below_compass + 4 + 260 + 0/0，收尾衰减回 280。
