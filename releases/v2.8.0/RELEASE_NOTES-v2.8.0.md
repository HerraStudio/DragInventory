## ③ 重合缺陷根因（源码级实证）

LDLib2 的 `UIElement` 绘制链工作在**绝对屏幕坐标**（`drawBackgroundTexture` 直接传
`getPositionX()/getPositionY()`，全程无控件局部平移——vineflower 反编译 2.2.40 all-jar 实证），
而 `SoundPrintWidget` 误用了控件局部 Y（`baselineY = 0.5f`）——整条声纹画在屏幕顶端
y≈0.5 处，与 `offset_y=0` 顶部对齐的方位条完全重合。设置界面的合成预览因调用方先
`pose.translate(0, py)` 平移到预览锚点，未暴露该缺陷，导致 v2.7.0 发布前静态自检未命中。

修复：`drawSoundprint` 全面改绝对坐标（HUD 用 `getPositionY()`，预览显式传 y 参数）；
布局层按用户策略升级为"实时识别方位条 UI 真实位置"——反射读取 `CompassHud` 活动
`CompassWidget` 的 Taffy 布局解析值（本帧真实屏幕几何），叠加 `CompassConfig.SCALE`
的视觉换算（方位条缩放以 y=0 为锚：视觉底边 = (top+height)×scale），声纹布局值再除以
自身 SCALE 补偿自身绘制的同锚缩放；反射字段句柄静态缓存 + 失败哨兵，任何一步失败
回退与 `CompassHud.syncLayout` 同式的配置数学。声纹依旧零修改 compass 包任何代码。

## ② 连贯显示两道机制

- **linger_ms（默认 650，可调 300~1500）**：声音停止后满能量保持窗口。v2.7.0 固定
  260ms 小于人类脚步间隔（~450ms），步与步之间能量窗回落再刷新，表现为"一直在闪"；
  650ms 覆盖步间隔后连走期间时间窗因子恒为 1，能量不回落。停步后满能保持 650ms
  再线性淡出（脚步 1.25s / 枪声 0.85s）+ release 弹簧尾巴——即"暂停 0.5~1 秒后消失"。
- **motion_persist（默认开）**：每 client tick 扫描半径内 LivingEntity（在地面 + 水平
  速度 > 0.06 m/t，排除本地玩家；潜行静步 ~0.03-0.05 不触发），命中已有脚步源即续期
  且声纹随行走者平滑滑移（位置每 tick 跟随），无匹配源则按速度新建（覆盖刚进入半径 /
  超耳距但仍在 20m 检测半径内的走动者）。枪声源不参与续期（枪手走开时枪声按自身
  linger 淡出，其行走由脚步源表达）。

## ① 自声枪声投影（测试语义）

自己的枪声发自体内（dx=dz=0），直接算方位 `atan2(0,0)=0` 恒指北——面朝其他方向时
声纹落在视野外毫无测试价值。现按"枪口在我眼前"语义投影到眼睛沿视线前方 4m：
- 声纹落在条带正中（bearing = 当前朝向）
- 俯仰联动：抬头仰射 → 上箭头 + 上排增强（4m 摆幅足以触发箭头阈值 0.22）
- 距离近 → 距离衰减小 → 能量足（形态测试不受距离干扰）
- 与 `ignore_own_sounds` 独立：关掉此项后自声枪声回落为按 ignore_own 过滤

## ⑤ 模拟声源测试功能

- **入口**：`/herrasoundprint`（别名 /soundprint /sp）设置界面第六页签"测试"；
  或指令 `/sp sim on|off|toggle|type <footstep|gunshot>|bearing <0-359>|distance <2-20>|mode <static|orbit|random>`。
- **节奏**：脚步每 420ms 发声（低于 linger 650ms，表现为连续行走）；枪声每 2200ms
  （完整看完一次爆发-淡出曲线）。开启瞬间立即发声，换类型立即发一声。
- **移动模式**：static 固定方位；orbit 18°/s 匀速旋转（校验声纹滑移与方位条逐像素同步）；
  random 随机游走（每 1.2~2.4s 重定方位 ±50°、距离 ±2.5m，指数趋近）。
- **管线**：模拟样本与真实声音完全同路（同样的停留 / 淡出 / 聚合 / 动画），实机校验
  即真实观感。位置数学与 bearingFrom 互逆（0°=北=-Z）。
- **生命周期**：会话级状态不落盘（重启游戏归零，避免忘关幻声纹）；退出世界自动停发，
  参数保留（重进世界继续按原设定模拟）。

## 实机复测要点

1. **位置**：进世界确认声纹带出现在方位条正下方（不再重合）；拖动方位条
   （/compass 设置界面改 offset/宽度/缩放/皮肤）确认声纹当帧跟随。
2. **连贯**：找一只生物（或另开账号）：它走动 → 白声纹持续点亮且随其滑移；
   它停步 → 约 0.65s 后开始淡出。自己走动不出声纹（自声脚步仍过滤）。
3. **自声枪声**：开一枪 → 红色枪声声纹在条带正中爆发后淡出；朝天开枪 → 上箭头。
4. **宽度**：老存档升级后单簇声纹应明显变宽（67px vs 26px）。
5. **模拟**：`/sp sim on` → 默认东 90°、12m 处白声纹持续；`/sp sim mode orbit` →
   声纹匀速绕圈滑移；`/sp sim type gunshot` → 红声纹每 2.2s 爆发一次；
   `/sp sim off` 关闭。
6. **linger 调节**：设置界面"动画"页声纹停留滑条 300~1500ms 实时生效。
