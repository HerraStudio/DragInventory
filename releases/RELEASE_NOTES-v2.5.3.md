# Drag Inventory 2.5.3 —— 键位标签、小地图尺寸、快捷键说明与滤镜重做

本版针对 2.5.2 实测反馈做出四项改进：按键绑定里的键位标签澄清、小地图默认尺寸缩小、大地图快捷键说明写全、六种滤镜预设全部重做。

改进一——按键绑定标签澄清：在原版"选项 → 控制 → 按键绑定 → Drag Inventory"分类里，"打开战术地图"改名为"开/关大地图"、"地图界面开关"改名为"开/关大地图界面显示"、"清除标点"改名为"清除地图标点"——此前想调整打开大地图的键位时，按"大地图"检索不到对应条目（该分类下三个地图键位均可自由改键，地图内的说明文字会动态跟随）。M、C 两个键位同时补充了 IN_GAME 冲突上下文，与原版游戏内按键的冲突检测口径一致（屏幕内按 M 关闭地图的行为不变）。

改进二——小地图默认尺寸缩小：左上角常驻小地图默认边长从 128 像素缩小到 96 像素。从旧版本升级的玩家无需手动改——首次加载时若检测到配置里仍是旧默认值 128，会自动收敛到 96 并保存（此后你再自改的任何尺寸都会被尊重）。设置 GUI 行为页与 /map minimap size 仍可随时在 64~256 像素间调整。

改进三——大地图右下角快捷键说明写全：完整界面与清屏模式现在共用同一条完整说明（清屏模式此前只提示"按 H 显示界面"一条），字号从 0.7 缩小到 0.6，内容覆盖全部操作——M/ESC 关闭、左键拖动、右/中键标点、滚轮缩放、空格居中、1/2/3 标点类型、H 界面开关、C 清除标点；H 与 C 改键后说明中的键名动态跟随。

改进四——六种滤镜预设全部重做，向原游戏地图风格对齐：

- 三角洲：近黑的蓝灰地面 + 冷白建筑，接近原作地图"暗底浅白建筑"的强反差二值化观感；
- 塔科夫：米黄纸面地图基调 + 暖米白建筑，柔和不丢细节；
- 暗区突围：夜视仪墨绿——深绿地面 + 近中性灰白建筑；
- Apex：提亮增饱和，色彩鲜活干净；
- PUBG：自然色调轻度去饱和 + 暖褐大地，接近卫星遥感；
- 关闭（默认）：彩色原色不变。

技术上的变化：烘焙管线加入 S 曲线（暗部更沉、亮部更亮且不产生色阶反转）、地面目标色与墙体目标色（各风格的地面基调与建筑色分离，形成原作式反差）；房门的青绿与楼梯的暖金强调移到滤镜之后——旧版强调会被去饱和冲淡（三角洲下房门几乎变灰），现在任何滤镜下门恒为亮青绿、楼梯恒为暖金。切换滤镜即时全量重烤，无需重进游戏。

适配说明：旧配置无需手动改动（minimap.size 若为旧默认 128 会自动收敛到 96，并写入一次性标记 minimap.size_retuned）。

适用：Minecraft Java 1.21.1 + NeoForge 21.1.251 + LDLib2 2.2.40（或 2.2.41），Java 21。直接替换 mods 内旧版 JAR 即可。
