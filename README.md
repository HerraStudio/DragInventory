# Drag Inventory — 拖动物品栏与 LDLib2 快捷栏

适用：Minecraft Java 1.21.1 + NeoForge 21.1.251，Java 21。
版本：1.5.3。界面和拖拽功能在客户端运行，玩家基础最大生命值 100 和体力消耗、恢复在服务端计算。体力通过 NeoForge 数据附件同步给玩家自己的客户端，不添加物品。1.5.0 起内置方位条 HUD（顶部罗盘，五套游戏风格皮肤，使用手册见 `wiki/方位条HUD.md`）。

1.4.0 增加 GWO 枪械 HUD 配套：快捷栏第 1–4 格按固定位置表示两格主武器、手枪和近战武器；滚轮和数字键输入立即更新槽位，HUD 平移动画独立播放，不等待收枪动画。GWO 未安装时不会加载其专用显示层。

1.4.1 起将候选槽位横向排列在 GWO 原生枪械 HUD 上方，以“按键＋对应武器的白色透明轮廓贴图”替代主武器、手枪、近战文字。读取槽位中实际武器的 HUD 贴图，未提供时使用其物品图标生成白色轮廓；更换武器自动更新。图标表示内容包定义的武器外形，不重建配件模型。

1.4.2 自动跳过第 1–4 格中的空槽：HUD 向前补齐，按键按现有非空槽顺序重新对应 1、2、3、4，并显示设置中实际绑定的键名。例如物理第 2 格为空时，原第 3、4 格对应按键 2、3。滚轮立即选中下一个非空槽；只有一把武器或全部为空时保持当前选择，未对应武器的 1–4 按键不切槽。物品保留在各自背包格中，按键 5–9 仍对应原第 5–9 格。

1.4.3 为当前武器的 GWO 主面板加入平移和缩放过渡：切枪后，新枪图、弹量、备弹和模式图标一起从侧下方滑入，在 240 毫秒内从 84% 放大回正常大小。方向随前后选择变化；连续输入立即切到最新武器并播放其过渡，重复选择同一武器不会重新触发动画。

1.4.4 在右下角底部控制行增加“按键＋激光”：仅在当前枪械装有激光配件时显示，读取 GWO 实际激光绑定键，开启时文字高亮并带下划线，关闭时变灰。战术姿态和射击模式的字母按键重绘为抗锯齿高清图标，以 8 倍 HUD 分辨率生成，并随改键更新；三个控制组留出独立间距，长键名自动适配面板宽度。新控制行随主武器 HUD 一起平移、缩放。

1.4.5 为枪械 HUD 加入轻微惯性晃动：转动视角时根据水平、垂直角速度偏移并轻微倾斜；实际疾跑移动时节奏起伏；起跳与落地时短暂回弹；GWO 每次实际射击产生轻微震动。枪图、弹药、控制提示和上方候选行共享同一晃动，叠加既有切枪过渡。按反馈将幅度提高约 25%，视角跟随采用柔和阻尼，疾跑采用正弦起伏，跳跃/开火和切枪采用非线性缓入缓出。停止后平滑回正，静止时没有随机抖动；打开界面、暂停、离开武器槽或更换玩家时清理状态，切枪不携带上一把枪的开火震动。

1.4.6 加强 HUD 的力量感：视角跟随、疾跑和跳跃的主要幅度提升至 1.4.5 的约 2–3 倍；开火冲击在约 22 毫秒内到达峰值，随后用 180 毫秒恢复并小幅反向回弹，最后 100 毫秒回正。起跳和落地也带短促冲击与约 12% 的反向回弹。延续非线性曲线，静止时保持稳定。

1.4.7 统一激光关闭状态的按键颜色：关闭激光时，字母键帽使用与其他控制提示相同的灰色绘制；开启时恢复白色。直接复用高清键帽的状态颜色，保持背景和字母明暗一致。

1.4.8 增加战术标点：中键单击标记地点或掉落物，300 毫秒内双击敌人显示红色感叹号。所有标点显示实时整数米数，靠近准星自动淡化，离开屏幕显示方向箭头；重复目标刷新，60 秒后自动清除。

1.4.9 将所有类型标点的总数限制为 5 个；新增第 6 个删除最早加入的标点，以此类推。重复目标只刷新时间、位置及出现动画，不增加数量或改变删除顺序。中键双击窗口由 300 毫秒放宽到 450 毫秒。敌人标点固定在点击命中位置，不跟随生物移动，其死亡或移除也不提前清除标点。新建/刷新标点播放 320 毫秒非线性缩放、上移和淡入动画，轻微回弹后稳定。

1.5.0 新增方位条 HUD（顶部罗盘）：中央高亮当前度数，两侧滚动主方位文字与角度刻度，临界阻尼弹簧动画，359°↔0° 跨越走最短路径不反向甩动。内置五套游戏风格皮肤：三角洲（默认）、绝地求生、Apex、战地、使命召唤；六组配色可自由组合并逐项覆盖颜色。`/com` 三个字母唤出像素游戏风设置界面：六页签单屏容纳全部选项，顶部实时预览支持拖拽转向与自动摆动。只读接入战术标点体系，标点映射到对应方位并按类型分形；死亡自动标记落包点，重生后可沿方位条导航。“开关方位条”可绑定按键（默认未绑定）。`CompassApi` 供其他模组读取朝向、注册标点提供者、监听基数方位事件。方位条为独立 HUD 图层，不触碰本模组其他 HUD 代码。

1.5.1 按用户提供的实机参考图逐像素还原三角洲、绝地求生、Apex 三套皮肤：绝地求生的金色 N 与字母位粗刻度、三角洲的 [ 37 ] 方括号读数与垂挂刻度、Apex 的悬浮式布局各自还原；默认刻度密度对齐参考图（数字间隔 15°、细刻度 5°）。修复刻度与标签的坐标空间缺陷，此前仅默认位置正确，调大偏移或打开设置预览时刻度会漂移。设置界面按参考配色 Mythic 化（暖深灰+金），每行新增单项恢复默认按钮。

1.5.2 修复配置保存竞态：NeoForge 配置文件监视线程异步重载会覆盖窗口期内的用户修改（表现为开关失灵、配色跳回），现以写前日志加重载对账两轮收敛。方位条标点与游戏内实际标点完全同款（红感叹号/白菱形/物品贴图），测试标点 60 秒过期与失效复检对齐战术标点生命周期。布局页签新增全屏拖拽定位（蚂蚁线+坐标读数+滚轮调宽）、四向快捷对齐与屏宽占比预设；条宽上限放宽到 960，刻度按参照密度自适应加密。三套菜单主题（琥珀/科技/绯红）与关闭动画、页签指示条等动效加入。

1.5.3 修复三处实测视觉问题：次方位字母与度数重叠时自动碰撞避让跳过数字（五皮肤通用，默认配置不触发）；设置菜单内容区整体剪裁，子选项翻动不再盖住页签与主选项；预览演示始终居中于演示框并做盒内防溢出裁剪。

## 战术标点操作

- 游戏内中键单击，约 450 毫秒确认后生成白色菱形地点标点；若命中掉落物，则显示该物品的原生图标。中键在正常游戏视角下替代原版“选取方块”，菜单和背包中的中键沿用原行为。
- 450 毫秒内双击，第二次准星命中敌人时生成红色感叹号。单击生物仍是地点标点；双击非敌人按单击处理，瞄准掉落物优先显示物品图标。对天空单击不产生虚构地点。
- 敌人包括原版/模组的 Enemy 敌对生物、非同队玩家，以及客户端能够识别其攻击/仇恨状态的生物；被动动物和同队目标不会显示红色敌人标点。
- 初始射线范围 128 格，仅选取已加载、射线可见的目标，方块遮挡会阻止选取后方实体。敌人标点固定在点击命中的世界位置，与普通地点标点一样；掉落物标点仍跟随物品，拾取后清除。标点不会因遮挡而隐藏。
- 相机与标点的欧几里得距离向下取整，1 方块 = 1 米，格式如 `12m`。使用游戏实际视图/投影矩阵，适应 FOV、瞄准缩放、镜头倾斜和 GUI 比例。
- 准星距标点 75 个 GUI 单位以内平滑淡化，中心最低不透明度 20%；距离文本和物品图标一起变化。物品图标沿用原版/资源包/模组的原生物品渲染，三维方块也可淡化。
- 标点生成或刷新后按实际时间保留 60 秒，打开菜单仍计时。同一实体以 UUID 去重，同一方块表面重复标记也会刷新；单击地点再双击同一实体会替换为敌人标点。
- 掉落物拾取、销毁或卸载后，于客户端收到更新的下一帧移除对应物品标点。固定的地点和敌人标点持续 60 秒，或在超过 5 个时被最早优先替换。退出世界、切换维度、玩家重生会清空，背包/聊天/暂停/隐藏 HUD 时不绘制或接受新的标点。
- 地点、敌人、物品共用 5 个名额。新目标挤出最早加入者，重复目标刷新不会改变加入顺序。新建/刷新时，图标、距离和边缘箭头同步播放 320 毫秒非线性出现动画：55% 缩放起步，略微放大回弹到 100%，从下方 8 个 GUI 单位上移，前 130 毫秒淡入；与准星靠近时的淡出叠加。
- 当前为本机客户端标点，不广播给队友，也不跨世界保存。

## 安装

将 `drag-inventory-1.21.1-neoforge-1.5.3.jar` 和 `ldlib2-neoforge-1.21.1-2.2.40-all.jar` 放入游戏实例的 `mods` 文件夹，移除旧版 Drag Inventory JAR。
不要把源码 ZIP 或 sources.jar 放进 mods。LDLib2 前置沿用 1.2.x，开发与测试固定使用 2.2.40。
单人游戏无需额外设置；联机时服务端和客户端都需要本模组的 1.5.3 JAR，以同步体力、执行行动限制并应用真实的 100 生命值规则。独立服务端不需要 LDLib2（依赖仅限客户端）。方位条 HUD 为纯客户端功能，服务端不参与。

## 生命值与体力条

- 玩家基础最大生命值设为 **100 点**（原版为 20 点），新玩家及死亡重生后满血为 100。
- 登录时若存档保存了其他基础上限，会改为 100 并保留当前血量比例；已是 100 上限时登录不会回血。
- 药水、装备等属性修饰符继续生效，因此生命提升效果可让最终上限超过 100；不改伤害和食物机制。
- 血条位于左下角，使用白色细长填充条；左侧为玩家当前皮肤的 2D 头像，下方为玩家名字。没有数值、加号、标题或装饰面板。长名字自动缩小以完整显示。
- 删除黄色饥饿条，改为位于五格快捷栏上方、与其等宽的白色体力条；没有数字、图标或标签。两条状态条共用细边框、深色空槽和白色填充样式。
- 消耗/受伤后平滑缩短，原填充位置的淡灰色尾迹自然收拢；恢复时平滑增长。体力不超过 20% 时填充变为红色，恢复超过 20% 后恢复白色。
- 头像血条随窗口宽度缩短，极窄界面时上移少许，避免与快捷栏、副手重叠。
- 体力上限 **100**，实际移动中的疾跑每秒消耗 **12**，每次跳跃消耗 **10**；停止消耗约 **2 秒（40 游戏刻）**后每秒恢复 **16**（按正常 20 TPS 计）。走路和站立不消耗；原地保持疾跑标记不扣体力。
- 创造、旁观、飞行、鞘翅滑翔、乘坐和睡眠不消耗体力。体力不会小于 0 或大于 100；存档保存当前体力，死亡重生恢复至 100。
- 红色区间（体力大于 0 且不超过 20）：不能开始新的疾跑，但已经进行的疾跑继续消耗至 0 才中断；仍可跳跃，剩余不足 10 时也允许完成一次跳跃并耗尽剩余体力。
- 体力为 0 时中断疾跑，同时禁止开始疾跑和起跳。恢复到大于 0 后可跳跃，恢复到大于 20 后可重新疾跑；不需要等到回满。
- 被禁止的操作不会扣体力，也不会重置恢复等待时间；再次成功跳跃或疾跑消耗才重置 2 秒等待。普通移动、碰撞、饥饿等原版停止疾跑条件继续生效。
- 疾跑启动和跳跃入口在客户端与服务端都检查体力。原版食物、饥饿、冲刺条件和自然回血规则仍然生效，仅隐藏食物显示。
- 吸收生命计入血条比例；创造、旁观和 F1 隐藏状态条。经验条与等级数字继续隐藏。
- 可通过 `StaminaState.java` 调整体力参数，通过 `StatusBar.java` 调整外观和动画。

## 新快捷栏

- 使用 LDLib2 `ModularUI`、`UIElement`、`ModularHudLayer` 与纹理组件制作，替换原版 HOTBAR 层。
- 只显示原快捷栏第 5–9 格，隐藏左侧第 1–4 格及所有按键编号；选中格为白边、较亮底色。
- 五格连续排列，每格 24×24，总宽 120 个界面像素，整体居中靠底，距底部 3 像素。体力条与槽位上沿间隔 4 像素。
- 实时读取玩家快捷栏，保留数量、耐久、物品冷却和获得物品动画；副手槽随主手方向调整。
- 隐藏经验条及等级数字，只影响显示，经验获取和消耗规则保持原版。
- 为状态条预留固定高度，护甲、氧气、坐骑血量、骑乘跳跃条及物品名称显示在其上方。
- 滚轮在武器第 1–4 格的非空槽之间循环；数字键 1–4 按非空槽顺序选择，5–9 按原物理槽选择。副手交换沿用原版操作；F1 隐藏快捷栏，旁观模式保留原版旁观菜单。
- 第 1–4 格仅从底部快捷栏隐藏，物品不会删除；剩余五格仍对应原键位 5–9。隐藏格选中时不会高亮其他格。物品堆叠数量继续显示。
- 参考图中的枪械、工具箱等来自对应物品模组，本模组不添加这些物品。
- 可在 `src/main/java/dev/draginventory/client/ReferenceHotbar.java` 调整尺寸、可见槽位、颜色和边框。

## 方位条 HUD

- 顶部中央方位罗盘：0° = 北、顺时针增大；中央高亮当前度数，两侧滚动方位文字与角度刻度。显示视野范围（60°~360°）、刻度间隔、主方向字号、中文方位字全部可调；位置可拖拽或精确偏移，条宽 120~960。完整使用手册见 `wiki/方位条HUD.md`。
- 五套皮肤：`delta`（三角洲，默认）、`pubg`（绝地求生）、`apex`、`battlefield`（战地）、`warzone`（使命召唤），按各游戏原作还原；六组配色（极光/霜白/琥珀/绯红/紫罗兰/石板）可与任一皮肤组合，accent/文字/刻度/背景五通道可逐项覆盖，内置 HSL 取色器。
- 动画：临界阻尼弹簧（无过冲无余振）、359°↔0° 最短路径、亚度精度平滑；方位吸附辅助、惯性倾斜、入场动画均可开关。
- 指令：`/com`（最短别名，无参直接唤出设置界面）、`/compass`、`/herracompass` 三条根指令等价，含 style/palette/offset/scale/opacity/width/range/smooth/markers/test/copy/info/reset 等 18 个子命令；非法参数报错并列出合法值。
- 设置界面（`/com` 唤出）：六页签（外观/布局/显示/标点/动效/颜色）单屏容纳全部选项；顶部实时预览与 HUD 同渲染路径，支持拖拽转向、模拟滑杆、自动摆动；布局页签有全屏拖拽定位、四向快捷对齐、屏宽占比预设；三套菜单主题；每行带单项恢复默认按钮。
- 战术标点联动（只读）：敌对红感叹号、位置白菱形、物资物品贴图自动映射到对应方位，带实时距离/文字标签与平滑脉冲；视野外侧的标点吸附到条带边缘压暗并附方向箭头；屏外更远的不显示。标点颜色与主题高亮色自动撞色规避。
- 死亡标点：死亡自动在落包点生成红色 X（同维度显示），重生后沿方位条导航，活着靠近 8 米自动清除；可开关。
- 独立 HUD 图层注册，与快捷栏、体力血条、枪械 HUD 互不影响；配置写入 `config/draginventory-client.toml`，改动 500 毫秒防抖落盘，设置界面/指令/手改文件三方同步。
- `CompassApi` 联动门面：其他模组可反射读取朝向与角速度、注册标点提供者、监听基数方位进入事件；未安装时安全降级，不抛异常。

## 操作

### GWO 枪械 HUD

- 滚轮只在第 1–4 格的非空槽之间循环；从第 5–9 格滚动时按方向进入最前或最后一个非空武器槽。
- 数字键 1–4 立即选择按顺序排列的非空槽，HUD 按键同步更新；支持在原版按键设置中改绑。创造模式的快捷栏预设保存/加载组合沿用原版。
- 空槽完全省略；非空但缺少可用贴图的物品仍保留按键和短横线。只剩一把武器时，候选行为空，滚轮保持该武器。
- GWO 的原生枪械轮廓、弹匣和备弹信息继续由 GWO 绘制；本模组在上方绘制其余三个武器位的编号、白色贴图及平移动画。当前槽位从候选行中排除。
- 候选贴图自动裁掉透明边缘、保持比例，随 GWO 的屏幕缩放定位；贴图缓存有容量限制，资源重载时释放并重新生成。
- 选择提交与 HUD 动画分离，快速连续输入以最新槽位为准。
- 当前枪械的 GWO 主面板单独做平移和缩放；上方候选行沿用原有平移动画。缩放围绕主面板中心进行，结束后恢复原生尺寸及位置。近战没有 GWO 原生弹药面板，候选行正常显示。
- 底部战术姿态、射击模式和激光使用动态高清键帽；安装激光后才显示激光提示。示例中的 Y 是测试绑定，正式版本始终显示玩家在 GWO 中设置的实际按键，不自动修改绑定。
- 视角、疾跑、跳跃与开火触发轻微 HUD 晃动；以实际经过时间计算，支持不同帧率。位移上限为 GWO 面板坐标横向 7、纵向 8，倾斜上限 1.5 度；HUD 原生缩放继续生效。站立、原地按住疾跑及未实际射击时不会制造随机震动。

| 操作 | 结果 |
| --- | --- |
| 左键短按并原地松开 | 物品保持原位 |
| 按住左键约 180 毫秒，或按住后移动至少 4 个界面像素 | 拿起并拖动 |
| 拖到目标格松开 | 放下、合并同类物品，或交换不同物品 |
| 同一物品格在 250 毫秒内双击 | 执行原版 Shift＋左键的 QUICK_MOVE 快捷移动 |
| Shift＋左键 | 与普通左键相同，不再触发快捷移动 |
| 拖到无效格或界面外松开 | 优先放回来源格，否则尝试放入玩家背包 |

原版双击“收集同类物品”功能被替换。双击只处理当前格，转移方向沿用原容器规则。
左键拖过多个格子不再平均分配，只在松开所在格放置。
右键拆分/逐个放置、Shift＋右键、数字键、F、Q 保留原版行为；正在左键拖动时拦截其他物品操作，避免交叉操作。

## 边界行为

- 背包、箱子、熔炉、工作台等继承原版容器界面的页面使用同一套输入修改。
- 合并后的余量、交换出来的物品优先放回来源格。
- 合成/交易等结果格不能放回时，尝试放入玩家背包。若全部合法格子都没有空间，余量保留在鼠标上，可再用左键放入空格。
- 从原版右键操作留下的鼠标物品，可在目标格按下并松开左键放下。
- 松开到界面外不主动丢弃；需要丢弃时使用原版 Q。关闭界面沿用原版对鼠标物品的处理规则。
- 创造模式目录的 QUICK_MOVE 沿用原版含义：双击目录物品取一整组到鼠标上，与生存模式容器间转移不同。
- 尚未逐项实测创造模式目录、联机和其他鼠标整理模组的组合；完全重写输入处理的第三方界面可能不受本模组影响。

## 构建与测试

安装 JDK 21 后，在源码目录执行：

```powershell
$env:JAVA_HOME = '你的 JDK 21 安装目录'
.\gradlew.bat build
```

成品位于 `build/libs/drag-inventory-1.21.1-neoforge-1.5.3.jar`。
NeoForge 构建版本固定为 21.1.251。发布 JAR 包含通用生命值规则及客户端 HUD/Mixin；自动测试入口不包含在内。

- 输入逻辑测试：`.\gradlew.bat test`
- 战术标点与方位条桥接集成检查：`.\gradlew.bat runClient -PmarkerSmoke`（真实实体、数据包与原生渲染，验证敌对/掉落物/位置标点并截图，然后退出）
- 开发客户端：`.\gradlew.bat runClient`
- 自动启动检查：`.\gradlew.bat runClient -PsmokeTest`
- 游戏内快捷栏检查：`.\gradlew.bat runClient -PhotbarSmoke`（创建独立超平坦测试存档，验证布局与缩放并截图，然后退出）
- GWO 槽位规则和动画状态由 `WeaponSlotsTest`、`WeaponSwitchAnimationTest` 覆盖。
- `WeaponHudMotionTest` 覆盖视角方向与跨 180 度边界、疾跑/静止/空中、起跳落地、开火衰减、叠加限幅、30/144 FPS 一致性以及长帧间隔和切枪清理。`HudMotionSmoke` 在实际客户端转动视角、疾跑、跳跃、开火并录制 HUD，检查变换恢复、回正及打开背包后的复位。
- GWO 实际游戏检查：`.\gradlew.bat runClient -PweaponSmoke -PweaponGameDir=run-weapon-gwo`。需在该隔离目录预先准备合法取得的 GWO 2.12.87、GWO Default Gun Beta1.4 和近战内容包；第三方文件不随源码包分发。检查真实武器、按键 1–9、连续滚轮、白色贴图像素、GUI 2/3/4、空槽、换武器与资源重载，并保存截图。激光检查会装入真实配件，验证按 Y 实际关闭/开启、改绑 K 后的提示及未安装配件的枪械。

启动检查会在界面加载并验证 Mixin 后自动退出；`src/smoke` 只在传入 `-PsmokeTest` 时编译，正常构建不包含自动退出功能。
`src/hotbarSmoke` 和 `src/weaponSmoke` 同样仅用于检查，不包含在正常发布 JAR 中。检查后请用不带检查参数的 `clean build` 生成发布包。
